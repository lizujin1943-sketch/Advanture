# 拖拽批量建造

进入建造模式后，按住左键拖动预览，松开提交可建地块。绿色为可建且个人材料足够；红色为占用、缺料、不相邻或其他限制。单击仍能建一格，材料配方保持原配置。

## 职责与确认边界

- `PlatformBuildDraft` 记录去重后的经过顺序、快速移动补格和整批材料预算；只使用确认帧的地块列表及 `Fisher` 值副本。规则统一调用 `PlatformRules.CheckPreview`，不修改权威库存、地块或预测态。
- `PlatformBuildBatch` 复制松开时的绿色候选，用已有 `PlatformBuildRequestBuffer` 每次保留一个事务。只有确认回执后才发送下一格；发送前再按最新确认态检查。失败回执是本批次的最终结果，不换 ID 偷偷重试。
- `PlatformConstruction` 负责输入、交互取消和把批次交给输入命令组合；`PlatformBuildPreviewPresentation` 用无碰撞、共享材质的对象池显示多格预览；`PlatformPresentation` 继续只呈现确认后的实际平台和相邻边界。
- 退出、失焦和失能取消未发出的意图；已交给发送缓冲的请求保留原 ID 等待回执。重开、重连／加载边界沿用 `ResetSession` 清空所有本地队列和预览。已建部分由原平台存档与回执保存。

不增加协议字段或存档字段，不修改真实扣料规则，不新增场景常驻验证组件。每个地块独立原子提交，整批可能部分成功；本批失败地块需要玩家重新操作。
