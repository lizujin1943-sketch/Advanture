# 连击实现记录

日期：2026-10-27。设计依据为 [游戏设计文档](hook-island-game-design.md#连续捕鱼与金币连击)。

## 已接入

个人连击由 `ComboRules` 维护，鱼、浮木、小／稀有宝箱与奖励事务一起提交。大宝箱在抵岸时冻结最终参与者并增加次数，`Landed` 阶段就是持久化的计数凭据；开箱、开箱失败与重试都不重计。

鱼获使用最终参与者增加后的最高档位，整条鱼加奖取整一次后均分、余数归主钓；鱼骨、木材及宝箱金币不加成。默认百分比为 `0,0,10,15,20,25,30,35,40,50`，第 10 次以后只增加次数。账本／库存提交失败不修改计数或部分发奖。

出杆的 `PendingCast` 保存尚未结算的结果。成功收获或有效钩中队友会清除此标记，随后空线回到手中不会误断连。钩中正在出杆的队友所导致的强制收钩也保留受钩者连击；主动取消自己的未完成收获仍断连。落水在状态切换时清零，持续在水中不会重复清零。倒地、死亡、离线与新局按既有权威流程清零。

浮木牵引补充了超线长解除，并与其他钓线一起在水球击退时回收；这些失败均在同一模拟帧清零连击。

## 配置与分层

- 确定性配置：`samples/HookIsland.Simulation/Data/Configuration/ComboConfig.cs`，禁用开关、HUD 起始次数、整数加成数组。无休息超时；起奖及封顶档由同一数组推导。
- Unity 配置：`samples/TacticalGame.Unity/Assets/HookIsland/Data/ComboSettings.asset`，由 `FishingSettings.asset` 引用；安装入口为 `Tools/Hook Island/Install Fishing Equipment`。
- HUD：`ComboHudAnimation` 只处理本地表现时钟，`ComboHud` 使用确认态绘制。3 次起只显示 `xN`，移除百分比、鱼钩和金币等图标及装饰条；颜色随加成由绿经黄、橙渐变成红。加成越高字号、弹跳幅度及柔光越明显，强度在最高加成处封顶，10 次以后保持红色并继续跳数。断连约 0.24 秒淡出；重连／新局／快照历史不会重播增加动画。
- 艺术字：`ComboLettering` 独立负责原创新字体的描边、挤出阴影和顶部高光；`Resources/UI/HookRushNumerals.ttf` 包含 0–9 及 x，完整内嵌字体数据，约 2.3 KB。约 13.5° 前倾、宽笔画与切角由字形本身提供，长计数按实际字宽自动缩小，保持显示区域内可读。字体源轮廓在 `scripts/generate-combo-lettering.py`；仅重建字体时需要 `fonttools==4.67.0`，游戏运行和 Unity 构建不依赖 Python。
- 显示位置为耐力面板右侧，不与生命、耐力、工具栏或建造面板重叠。3／10 阈值有轻量音效；已达上限后每次仍跳数但不重复阈值音效。
- 编辑器只读预览：`Tools/Hook Island/Preview Combo HUD`。该窗口位于 Editor 程序集，不注入运行中资源，也不成为正式场景组件。

调参时编辑 `ComboSettings.asset` 的 `goldBonusPercentByCount`（数组第一个元素对应第 1 次收获）及 `displayStartCount`。地图携带完整配置，同一房间不能混用不同曲线；已开始的局不因 Inspector 预览而修改权威配置。预览窗口用默认曲线展示 3／6／10／100 连击，`Replay bounce` 可重播动效；调参后的曲线及连续收获、互钩队友、空钩收回等衔接在新开的正式场景中检查。

## 联机与快照

`Fisher.Combo` 和当前杆的待结算标记进入快照，地图也包含同一份连击配置。沿用既有确定性输入、确认帧、重连和换局隔离机制；没有新增客户端奖励 RPC，也不在 HUD 修改权威状态。

版本为规则 25、状态 24、房间协议 25，输入格式维持 11；装备地图为 HIMG、状态为 HISG。旧版地图／快照／房间按既有兼容检查拒绝，不隐式迁移。安装脚本已重导出当前 `PlatformMap.bytes`。通用帧同步框架没有改动。
