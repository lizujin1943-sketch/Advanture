# 小渔夫角色与甩钩动画

Unity 平台场景使用 Blender 制作的圆润卡通小渔夫、骨骼和动作。角色身高约 1.063 m，20 根骨骼、9 个网格；Blender 源网格合计 4,900 个三角面，Unity 导入后为 4,820 个（含背包、钓竿及装备覆盖件）。衣帽沿用四名玩家的识别色；背包、装备覆盖件、鱼竿等级配色和游泳圈继续读取确认后的装备。

当前造型为饱满圆脸、低位置的小豆眼、微张嘴与小门牙、淡腮红、略歪的软渔夫帽、圆鼓雨衣及厚底短靴。使用少量轮廓环、平滑法线和局部倒角塑造柔和表面，不使用高密度细分。制作脚本在导出前检查 5,000 三角面的预算。原有骨骼、动作节奏和手臂约束保持一致。

## 资源与再制作

- Blender 源文件：`source-assets/characters/fisher/Fisher.blend`。
- 可重复制作脚本：`scripts/blender/create_fisher_character.py`。使用独立后台 Blender 运行，不打开或覆盖用户当前的 Blender 场景。
- Unity 模型、预制体、材质：`samples/TacticalGame.Unity/Assets/HookIsland/Art/Characters/Fisher/`。
- 运行时配置：`Assets/HookIsland/Resources/FisherCharacter.asset`。
- 导入命令：Unity 菜单 **Tools → Hook Island → Install Animated Fisher**。重新导出 FBX 后执行，更新材质引用、装备节点、动画片段和配置；不重建地图。

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python scripts/blender/create_fisher_character.py
```

源文件包含独立预览相机和灯光，FBX 只导出角色网格及骨骼。Generic 骨骼不启用根运动，线从 `LineGuide` 骨骼节点发出。双臂的旋转轴使用肘部弯曲平面的法线，避免挥竿穿过轴向时在中间帧翻转。

手臂姿态约束：双肘向外、向前弯曲，肩部位于外套两侧；待机和收线时将握竿点置于胸前。甩竿后摆时左手松开，在身体左侧配合动作，前挥结束后再握回竿柄，避免短手臂被强拉至另一侧肩膀并穿过躯干。右手始终连接竿柄。制作脚本会拒绝超出手臂长度的目标，不能通过拉长前臂来掩盖不可达姿势。

| 片段 | 时长 | 用途 |
|---|---:|---|
| Fisher_Idle | 2.0 s，循环 | 持竿待机与轻微呼吸 |
| Fisher_Walk | 0.8 s，循环 | 移动时腿部摆动 |
| Fisher_Cast | 0.6 s | 短后摆、上身转动、前挥、竿尖回弹、收势 |
| Fisher_Reel | 1.0 s，循环 | 回收及挂住目标后的持竿拉线 |

`FisherCharacterDefinition.castDuration` 只调整显示时长，不改变出钩速度、距离、冷却或命中时机。

## 状态与表现边界

`FisherAnimationView` 独立持有并释放 PlayableGraph；`FishingPresentation` 负责将玩家状态转换为动作观察值、装备显示与鱼线位置。两者均不回写模拟状态。

- 本人动作读取预测的 `Casts`，使输入立即得到反馈；队友动作读取确认态。确认回执不会重播同一次动作。
- 预测被回滚时取消相应动作，允许后续合法出钩再次使用该次数。初次生成角色时记录历史次数，加入房间或恢复快照不会重播历史出钩。
- 鱼钩坐标、挂钩目标与奖励始终读取确认态。没有新增网络字段或输入命令。
- 挥竿期间朝向沿发射方向，避免鼠标移动把身体拧离鱼线。
- 倒地、不可用、被队友拉拽、击退、未持竿、无游泳圈落水或本局结束会中断甩钩。回到待机后不补播旧动作。
- 重新开局、退出房间和视图销毁时释放动画图。旧的不含钓竿装备系统的场景仍保留原有钩枪外观。

本次新增四种动作。游泳、倒地和被钩救继续使用既有的姿态及游泳圈表现，没有新增独立的游泳或救援动画片段。
