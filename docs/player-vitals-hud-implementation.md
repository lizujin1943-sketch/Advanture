# 角色状态 HUD 实现记录

2026-10-27，2026-11-04 更新为无头像悬浮 HUD。适用正式木平台场景 `HookPlatform.unity` 的装备模式。

## 当前悬浮 HUD

- 按已确认的设计图实现白色文字、蓝色数字分隔和十段斜切生命条。部分填充的末端也沿同一斜率切斜，不用垂直边裁掉半格。左下角取消头像、头像框、姓名底板和区域底色；仍显示当前／最大生命、席位名字及异常状态。
- 医疗罐位于生命条左侧，纯白外轮廓始终可见；满罐填充延伸至瓶肩，只留细窄间隙。左下角数字显示个人剩余次数，储液腔按“剩余／配置上限”从下向上填充，耗尽后只显示空罐和 0。无头像、背板或 `V` 提示，填充与生命比例无关。
- 主界面不再绘制快捷物品栏、右下角武器图标、菜单图标和 Tab／B／F1 常驻按钮。数字键选择、背包、建造、帮助、菜单的原有输入入口保留；背包中的物品和绑定数据未删除。弹药从确认态独立读取，在右下角显示当前弹数与无限后备弹药；整组右、下边距为 24 逻辑像素，∞ 放大至 44 号粗体，与弹数共用同一行。临时换弹剩余时间显示在读数上方，不常驻显示 `R 换弹`。
- 任务摘要、详情抽屉和 J 入口暂时全部隐藏，`FishingOverlay.showObjectives` 默认关闭；任务推进、结算和胜利画面仍运行。需要恢复显示时开启该视图配置。个人金币在右上角悬浮显示，按实际字宽排列，图标与数字仅留 4 个逻辑像素间距；图标按数字可见字形的中心线对齐，补偿字体基线留白。
- 治疗确认后立即显示绿色增量，停留 0.15 秒，再由白色生命填充在 0.32 秒内追上；连续治疗不反复停顿，新伤害会取消绿色并转为受伤拖尾。读档、换装、复活或重新显示 HUD 只建立基线，不补播旧动画。当前生命数字始终显示确认值，不随动画变化。
- 队伍区域排除自己和等待加入的席位，单人完全隐藏，断线队友仍保留状态。任务抽屉展开时队伍信息下移，避免遮挡。可选 BOSS 的远处常驻指路条移除，靠近入口和挑战反馈仍保留。
- `HudPainter.FloatingText` 缓存字体样式并绘制细阴影；`Slanted` 复用抗锯齿遮罩，压窄填充区间后补回倾斜量，保持白色、绿色和红色边缘平行。销毁时释放纹理；不加载头像资源，不向场景添加相机或常驻验证组件。
- `HudLayout` 与 `FishingOverlay.PointerOverHud` 使用同一任务可见性开关，隐藏任务、队伍和移除的物品栏、工具按钮不留下透明拦截区。弹药为只读提示，不阻挡射击；可见建造面板仍阻挡点击穿透。

### 医疗罐实现分工

- `GameplayHud` 把本地玩家的确认态和 `HealingConfig` 交给 `HealingChargesHud`；后者决定次数文字和填充比例，不发送治疗请求。
- `HealingCanisterPainter` 只负责罐体外观，按确认稿描绘椭圆瓶口、镂空十字、肩部曲线与底部折角。300×400 设计坐标生成外壳与储液腔两张透明抗锯齿遮罩；后续帧复用贴图，裁切储液腔上部来降低液面，不压缩图形。比例只包含储液腔，排除固定瓶盖与图标留白。
- `HudPainter` 管理医疗罐绘制器的生命周期，退出视图时释放贴图。没有新增场景对象、常驻验证组件或资源包依赖。
- `HudLayout.LocalHealing` 与 `LocalHealth` 共同锚定左下角，底部边距为 32 逻辑像素。按最新反馈缩小医疗罐为 78×104，和生命条间隔 6 像素，次数文字等比缩放；扩建菜单在两者上方。界面绘制和鼠标遮挡使用同一组区域。
- 编辑器菜单 `Tools/Hook Island/Preview Local Health HUD` 可独立查看 3、2、1、0 次及不同生命状态；预览只用示例数据，不连接房间或修改真实角色。

## 显示与交互

- 自己的生命固定显示在屏幕左下角：本项目渔夫头像、当前／最大生命、十段血条、席位名字及倒地／死亡提示。白色分段表示正常生命，30% 及以下变红；确认受伤后损失段用红色短暂拖尾。头像边框使用席位颜色，低生命时轻微闪动。第一人称或角色出画面时仍显示。
- 队友继续在头顶显示血条；头顶锚点跟随头部骨骼，倒地、游泳和受击位移沿用表现层姿态。自己头顶保留扣血、治疗及钓鱼反馈，取消重复血条。
- 队友血条、角色面板生命文字、扣血数字、倒地／死亡标志沿用血红色。屏幕目标色为 `#C4121C`，在线性色彩工程中先转换 UI tint，防止最终显示偏粉。玩家席位颜色仍表示玩家身份。
- 自己的耐力未满时显示在角色左侧，以加粗的土黄色短圆弧连续填充，总弧度约 104°，没有刻度、常驻数字或背景面板；满值及倒地隐藏。队友收鱼或主动游泳且未满耐力时显示自己的圆弧。恢复、落水、游泳圈及低饥饿保留必要小图标；详细数值只在角色面板或悬停提示中显示。
- 扣除耐力时，实际填充立即缩短；浅金色残影停留 0.18 秒后向实际值收拢。队友血条受击先以白色标出损失段约 0.1 秒，再由血红色填充在约 0.32 秒内平滑退到实际值。本地分段条复用相同损失时序。新增反馈及验证见 [HUD 精简与收获反馈](hud-refinement-implementation.md)。
- 取消第三人称屏幕中心的十字准星；仍沿现有镜头中心射线瞄准。俯视指向瞄准、鼠标转向、落点提示、出钩及命中计算保持既有规则。

## 状态来源和职责

- `GameplayHud` 从同一份确认态取得本地生命与装备上限，复用 `HealthBarFeedback` 的受伤时序；`LocalHealthHud` 只绘制传入值，不预测、不发命令。`HudLayout.LocalHealth` 在 1280×720 基准下距离左边和底边各 24 像素，随现有 HUD 统一缩放；扩建面板移至其上方，血条区域阻挡穿透的鼠标操作。
- 头像为渔夫模型预渲染的四个席位 PNG，放在 `Resources/UI/Portraits/`。显式编辑器菜单 `Tools → Hook Island → Rebuild HUD Portraits` 可重新生成；使用隔离预览场景，并处理 Retina 的逻辑／实际像素差异。运行时只加载贴图，不增加相机。`Tools → Hook Island → Preview Local Health HUD` 可查看满血、受伤、低生命及倒地示例，不改世界状态。
- `PlayerVitalsOverlay` 只读取 `room.State` 确认快照，血量、当前耐力和装备上限来自同一快照。位置锚点跟随 `FishingPresentation` 显示的角色，不回写模拟状态。
- `HealthDamageFeedback` 比较连续确认快照的实际生命减少量；同帧重绘去重。120 毫秒内的短促伤害合并，最多保留每人 4 个数字，分列避免重叠，1.05 秒上浮淡出。一次显示可能合并两次渲染之间的多个模拟伤害，不是独立伤害日志。
- 初次接入、房间对象变化、局号变化、确认帧回退均建立新基线；菜单中继续观察但不积压飘字。生命装备卸下造成的上限裁切不当作伤害。治疗和复活增加血量不显示扣血。
- `StaminaArcPainter` 生成两张可重复使用的抗锯齿遮罩，用 UV 裁切绘制连续进度，不逐帧生成贴图。视图销毁时释放贴图。原 `ReelingStaminaOverlay` 横条移除，挣脱与合钓身份提示接入头顶区域。
- 未变更模拟规则、网络命令、协议或存档格式。没有向正式场景添加自动游玩组件。
