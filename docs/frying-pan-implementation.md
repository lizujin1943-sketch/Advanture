# 平底锅近战接入

2026-10-28。正式平台开局发放平底锅，背包内占 2×2 格；右手栏与钓竿互斥。`1`／`2` 切换，左键攻击。商人可补购，初始售价 60。

## 规则与边界

`samples/HookIsland.Simulation/Data/weapons.csv` 配置武器：1.6 m、前方 120°、25 伤害、6 帧前摇、18 帧动作、24 帧间隔、8 耐力、队友击退 1200 mm。模拟固定 30 Hz。`FishingSettings` 配置近战开关、初始发放、食人鱼生命（50）和硬直（0.5 s）。

- `MeleeRules` 负责装备查询、起手条件和整数扇形判定；`HookGame.Melee` 按角色／敌人身份稳定顺序结算。方向在起手时固定，倒计时越过命中帧只判定一次。
- 食人鱼受伤、硬直和重生；水怪仅打断蓄力，未新增水怪生命与击杀奖励。普通鱼不作为近战目标。击倒食人鱼不伪造捕鱼奖励；近战本身不增加或断开连击。
- 队友只击退不扣血，遵守房间整蛊与保护规则；掉水、倒地、被钩、购物等状态不接受此类整蛊。符合距离、状态和输入条件的队友救援动作也受保护，无效救援意图不授予免疫。攻击中停止主动移动，不允许更换右手装备；外部受击、倒地、拖拽与无圈落水取消攻击。
- 装备和商店沿用唯一 `InventorySystem`、库存批次及请求回执，不另建武器库存。失败请求不会自动重放，重复请求不再扣金币或生成物品。
- 近战复用已有 Fire 和库存输入；规则版本 28、状态版本 26、输入版本仍为 11。完整检查点保存动作阶段、命中计数与食人鱼伤势；旧玩法数据通过兼容校验拒绝，不进行隐式迁移。

## Unity 表现

`FryingPanArt` 共享程序化铸铁锅模型、木柄、金属材质与短音效；没有战斗碰撞器。`MeleeAvatarView` 在角色原有动画后叠加右臂两段 IK 与前摇／横扫／收势，沿用已确认装备显示持锅与隐藏鱼竿。动作采用预测姿态改善响应；声音、命中闪光观察已确认的攻击编号／累计命中数，重连不播放历史命中。

快捷栏仅显示两种工具图标、数字键、选中状态及冷却遮罩；背包、角色面板和地面掉落支持平底锅。图标由 `scripts/generate-frying-pan-icon.py` 生成，沿用原物品图标配色。正式 `FishingSettings.asset` 已启用并发放，`PlatformMap.bytes` 已更新并通过当前地图编解码往返校验。
