# 手榴弹实现

手雷属于钓鱼游戏示例，不给通用 `framework/` 添加物品、武器或 Unity 依赖。

## 操作

- 每个新角色获得一颗真实库存手雷，按 `4` 拿出。
- 按住鼠标左键：当前镜头沿原方向平滑后拉，释放鼠标指向甲板或水面；显示轨迹、落点误差圈与爆炸范围。
- 松开左键：冻结本次目标，服务器按固定帧出手。投出后回到之前的武器。
- 右键、切武器、打开菜单/背包/建造、失焦会取消尚未提交的瞄准；必须重新按左键才能再次瞄准。
- 已提交请求不能由本地取消；出手前倒地、断线或动作中断会保留手雷。已出手手雷独立存在。
- 右下角持雷时显示 `手榴弹 ×1`，没有库存栏、武器图标及 V/R 常驻提示。

## 规则与职责

| 位置 | 职责 |
|---|---|
| `GrenadeConfig` / `Data/grenades.csv` | 距离、飞行帧、弧高、引信、伤害配置 |
| `GrenadeCommand` / `HookInput` | 请求编号、物品实例编号、冻结目标坐标；拒绝混合互斥操作 |
| `GrenadeAction` / `GrenadeState` | 角色待出手动作、最终回执、已生成投掷物 |
| `GrenadeRules` | 整数轨迹、地形高度、遮挡、误差和伤害衰减；预览复用相同规则 |
| `HookGame.Grenades` | 固定帧推进、原子扣除与生成、落地引信、伤害和事件 |
| `GrenadeStateCodec` | 动作与投掷物保存、恢复和合法性校验 |
| `GrenadeRequestBuffer` | 重发首次冻结请求，等最终回执，失败不隐式重试 |
| `GrenadeAimInput` / `GrenadeController` | 本机按键归属、地面射线、请求排队和反馈 |
| `FishingCameraView.Grenades` / `GrenadeView` | 镜头、程序化手雷模型、预览、落地警示、爆炸与声音 |

30 Hz 下，动作开始后第 6 帧出手，只扣一次物品，生成帧不移动；动作共 9 帧。飞行 18～30 帧，落地后等待 24 帧（0.8 秒）爆炸，瞄准时不计时。距离 1.5～18 米，确定性落点偏移不超过 0.35 米。

爆炸半径 4.5 米，内圈 1.5 米造成 120 点伤害，向外线性降低到边缘 20 点，之后按护甲结算。包含自己和队友，不依赖整蛊开关。实体遮挡会阻止伤害。BOSS 同一部位多个代理只取一次最大伤害，眼睛不叠加爆炸暴击。

轨迹每帧细分检查共享障碍；被新障碍阻挡后停止水平运动并下落，不做弹跳。落水沉到水面下 0.3 米后启动引信。手雷不破坏平台或商人设施。

## 一致性与兼容

所有单位坐标、轨迹及伤害均由纯 C# 模拟推进。Unity 碰撞仅保护本机镜头，不决定命中；声音和爆炸只消费去重后的确认事件。保存包含出手前动作、空中轨迹、落地时间和成功/失败回执，不在读档或重连时补发初始手雷。

同步更新规则、输入、状态与房间版本：rules 41、input 17、state 36、room 33。旧存档/旧客户端明确拒绝，不尝试把旧字节解释成新输入。房间仍使用既有 Protobuf 与可靠 UDP，游戏输入及存档继续使用二进制格式。

## 验证

入口：`./scripts/verify-hook-grenades.sh`。输出在忽略目录 `artifacts/grenades/`。

15 项检查覆盖个人初始物品、第四槽、输入互斥、范围/误差/遮挡、固定出手帧、原子消耗、重复失败与成功请求、取消和成员停用、落地引信、自伤友伤、BOSS 本体与触手多代理去重、损坏快照拒绝、回切鱼竿属性、各阶段保存恢复与输入重放，以及四个真实 UDP 客户端同时投掷后的完整 checkpoint 与确认事件一致性。断线时投掷物的寿命通过正式成员停用事件验证；四客户端网络专项覆盖投掷、重试、落地和保存，不把它描述成真实断线重连测试。

Unity 的手雷、螃蟹朝向和第一人称表现共 11 项针对性测试通过，覆盖取消后必须重新按键、镜头保持模式与方向、反复跟随不累加位移、还原缩放、第一人称拿手雷时头部不遮挡视线。实际场景通过普通输入接口完成持雷、投掷、消耗、爆炸结束和回切验证；没有向权威状态注入对象。实际设备的鼠标选点手感需在解锁桌面后试玩。

相关回归已完成：钓鱼主测试 423 项、背包 59 项、角色 28 项、游泳 29 项、敌人 45 项、近战 19 项、枪械 41 项、螃蟹 26 项、复活 37 项、重开 19 项、BOSS 21 项及其输入适配器 6 项。主测试的 423 个用例名由现有测试程序集枚举，并与分组日志逐项核对，没有缺项或未通过项；审计记录在忽略目录 `.build/grenade/main-coverage.json`。

正式 `PlatformMap.bytes` 已从现有 `PlatformSettings.CreateMap()` 重新导出，只更新新增手雷配置后的配置表哈希，其他地图和配置字节不变。枪械与 BOSS 的旧测试也改为读取当前持枪实例的弹药，避免误读鱼竿槽而每发都换弹；BOSS 的 660 帧终点和战斗、奖励、存档断言保持不变。

本轮按 `./scripts/verify.sh` 的范围分组验收：首次串行执行在旧开发夹具失败后中断，修复后续跑对应组及剩余组，没有把该次中断记为入口退出成功。通用核心 148 项、存档 23 项、命令行 24 项、同步工具 6 项、可靠 UDP 31 项、UDP 集成 16 项及独立试玩 32 项通过；十万帧保存重放、四客户端一万帧和故障网络预测回滚均通过。测试环境为本机 macOS；本轮未新增 Windows 实机验证。
