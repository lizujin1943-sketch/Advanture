# 鱼游动、出水与入水粒子表现

已接入正式 `samples/TacticalGame.Unity/Assets/HookIsland/Scenes/HookPlatform.unity`。普通鱼游动时显示小气泡与临近出水时的短尾流；跃出时带起少量水滴和小水冠；入水时产生更明显的水冠、抛物线水滴及三层扩散泡沫。泡沫留在实际出入水点，逐渐扩散、淡出。鱼从钩上挣脱后落回水面，也使用新的入水粒子。

保持鱼的 2 倍展示倍率与既有轨迹、命中、奖励、联网和存档规则。普通鱼替换旧线框波纹；后续增加食人鱼水面游动表现，见文末。水怪保持现有表现。

## 调整入口

Unity Inspector 中选择 `Assets/HookIsland/Resources/FishWaterEffects.asset`。这是纯美术配置，不参与确定性规则或状态编码。

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `bubbleTint` | 淡青色，透明度 0.52 | 游动气泡 |
| `foamTint` | 青白色，透明度 0.76 | 泡沫、水冠 |
| `dropletTint` | 浅青白色，透明度 0.94 | 飞溅水滴 |
| `surfaceHeight` | 0.075 m | 相对当前海面的表现高度 |
| `swimBubbleCount` | 5 | 每条游动鱼的气泡数 |
| `takeoffDroplets` | 8 | 每次出水的水滴数 |
| `landingDroplets` | 12 | 每次入水的水滴数 |
| `rippleLifetime` | 1.8 s | 入水扩散波纹持续时间，出水为其 70% |
| `landingRippleScale` | 1.3 | 入水波纹范围倍率 |
| `crownLifetime` | 0.42 s | 入水水冠持续时间，出水为其 80% |
| `effectScale` | 1 | 特效整体倍率，另按鱼体型适度缩放 |
| `observationGapTicks` | 12 | 最大连续观察间隔；更大间隔不补播跨水事件 |

着色器通过配置资源直接引用，避免仅靠 `Shader.Find` 导致构建裁剪。启用了 Unity 自带的 `com.unity.modules.particlesystem` 模块，没有引入第三方包。

## 职责与联机边界

- `FishWaterEffects` 观察确认鱼状态，识别游动、跃起、入水和挣脱落水；按照确认帧计算粒子位置与淡出。首次快照只建立观察基线，不重放历史出水；相同确认帧重复显示时重建同一缓冲，不重复发射。
- `FishWaterParticles` 管理四个有容量上限的共享粒子系统：气泡、泡沫、水滴、水冠。网格、材质和数组一次创建、持续复用；销毁表现时统一释放。Unity 的自动粒子时钟暂停，网络等待不会自行提前播放落水。
- `FishWaterEffectsSettings` 维护美术配置；`FishWaterParticle.shader` 绘制柔边气泡、近连续波纹、柔边水滴与半透明水冠，不需要额外贴图。水滴为面向相机的 Billboard，其余为网格粒子。
- `FishingPresentation` 只传入确认状态；`CatchEscapePresentation` 的可选参数关闭普通鱼旧水花，保留挣脱姿态与其他调用方的默认行为。

鱼被钩住时不预定未来落水；换代、鱼种/重量/出生点替换、重开清理或确认时间倒退都会移除旧效果。超过观察间隔时省略历史水花，避免恢复快照或网络卡顿后集中补播。逃脱鱼回收换代时也清除剩余余波，可能在落水约 0.43 秒后结束该次效果。

网格粒子颜色使用 `Color32`，避免当前 Unity 2022.3 渲染器将浮点顶点颜色作为字节读取而造成颜色/透明度异常。水滴与水冠先保持可见，再在生命周期后段平滑淡出。

## 柔和水花与更明显的入水波纹

按后续视觉反馈，去除有棱面的长条水滴和六片尖瓣水冠。水滴改为柔边、半透明、略带高光的圆润粒子，缩短拉伸并降低抛起高度；水冠改为低矮、边缘渐隐的连续曲面，减少实体感。新增水冠为 185 顶点、288 三角面，仍只生成一次并由共享粒子系统复用。

入水后的三道波纹改为近连续细圆环，保留轻微起伏和不均匀亮度；范围倍率为 1.3，主体持续 1.8 秒，各圈相隔 0.16 秒，先保持可见再逐渐消退。扩散先快后慢，水冠消失后仍能看到波纹。出水的波纹保留更短的持续时间。

本轮未增加表现细节的实现镜像测试，复用既有确认态及渲染集成检查：最终 8 项全部通过。Unity 编译和正式本机 UDP 房间运行通过，实际采样展示倍率 2、四类粒子活动且无脚本或着色器错误；截图捕获时有 Unity 深度缓冲的 memoryless load/store 提示。逐阶段渲染与正式游戏截图均已查看，完整动图覆盖入水波纹淡出；预览、测试结果及实际参数记录位于 `artifacts/fish-water-vfx/soft-water/`，调整前截图保留在其 `before/` 子目录。临时预览场景已释放，未保存游戏场景改动。本轮未改动模拟或网络规则，未运行全仓验证、四客户端回归及发布构建。

## 食人鱼的水面游动

按后续确认，持续露出水面游动的鱼目前只指食人鱼。普通鱼保留潜游、跃起、入水的原有阶段。

食人鱼的模型中心从水面上方 0.12 m 调整到水线附近，配合海面的真实深度遮挡，让鱼身约一半浸水；保留背部、眼睛上部和背鳍。轻微起伏改用确认步数采样，相同确认帧不再随 Unity 实时时间抖动。

身体两侧有两层错开的浅色柔边水纹和六颗细小柔边水滴。最初的四道尾后短弧线已由下文的圆环尾迹替换。身体水纹按确认位置及朝向显示，大小按实际展示体长变化；停止前进后尾迹自行淡出，钩中、挣脱和重生时清除游动水效。

新增美术配置仍在 `Assets/HookIsland/Resources/FishWaterEffects.asset`：

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `piranhaBodyHeight` | 0 m | 食人鱼模型中心相对水线高度，另有 0.012 m 轻微起伏 |
| `piranhaWakeLifetime` | 0.5 s | 尾后圆环从出现到消失的时间 |
| `piranhaWakeStrength` | 0.8 | 尾浪与细水滴的强度 |

`PiranhaSurfaceWater` 只读取确认敌人状态，`EnemyPresentation` 负责模型位置、朝向及生命周期衔接。公共的 `WaterParticleBuffers` 管理有容量上限的粒子层、网格和材质；普通鱼的四层水效通过 `FishWaterParticles` 复用它，食人鱼仅创建自身需要的身体水纹、尾浪和水滴三层。所有层暂停自动模拟，由表现层按确认帧采样。不修改模拟位置、命中范围、伤害、网络命令、状态编码或存档。

验证：新增两项集成检查，覆盖半浸水、身体及尾部粒子、同一确认帧的姿态/粒子稳定、编码不变，以及钩中、挣脱、重生、倒退帧和清理。连同普通鱼水效、鱼模型、挣脱和敌人表现共 **13 项通过，0 失败**。Unity 编译通过，正式 `HookPlatform` 本机 UDP 房间运行采样为 `Playing=true`、`Failure=null`；3 条食人鱼的粒子数为身体水纹 6、尾浪 12、细水滴 18，展示倍率保持 2。

已查看斜俯视、低角度水线、俯视渲染，以及正式场景截图；预览连续动图使用真实 `EnemySystem` 巡游轨迹与正式表现类。临时预览对象已释放，正式场景未保存临时改动，验收后退出 Play。控制台无脚本或着色器错误，离屏渲染有 Unity memoryless 深度缓冲 load/store 提示。产物保存在忽略目录 `artifacts/piranha-surface-water/`。本次仅改 Unity 表现，未运行全仓验证、四客户端联机或发布构建。

## 圆形扩散波纹与尾迹修订

保留出水、入水瞬间的柔边水冠及飞溅水滴；只替换随后外扩的水面波纹。扩散层在世界 XZ 平面使用等长尺寸和径向圆环着色，移除原来的角度起伏、缺口及非等比拉伸。入水仍为三圈错时扩散、逐渐淡出，保留 1.8 秒主体时长和 1.3 范围倍率。斜视角下的椭圆是透视投影结果。

食人鱼尾后不再放置随朝向整体旋转的四道弧线。每 6 个确认步数，在实际经过的尾部位置留下一个小圆环，圆环独立外扩、淡出，转向不会移动已经产生的波纹。每条鱼最多保留 6 个历史位置；首次快照不补造尾迹，重复帧不重复发射，异常位移、观察间隔过大、钩中、重生和时间倒退均清理历史。身体接水纹和细小尾部水滴保留。

同步完成第三人称显示鼠标：原生指针可见、不锁定；相机继续读取相对鼠标位移，指针位于 HUD 时暂停转向并使用既有 UI 点击阻挡。视角切换、菜单和失焦沿用现有输入开关，未改变出钩瞄准或权威玩法。

验证：水效、鱼模型、挣脱及敌人表现 13 项通过；鼠标和相机局部检查另有 13 项通过。原有 `TwoUdpClientsWithDifferentPerspectivesMoveCastAndConfirmTheSameState` 在本次测试运行中失败（有时未在最初 6 帧移动，有时第 12 帧出杆计数未达到 1），共 27 项中 26 通过、1 失败。使用同样输入的临时双 UDP 客户端诊断可正常移动及各出杆一次，未改动模拟或网络代码，也未将这项失败描述为通过。失败结果留存于产物目录。
