# 晚加入与断线恢复实施说明

2026-10-22。房间容量为 1～4 人，人数到齐自动开始；房主准备好后可点击“现在开始”。后来玩家进入未使用的空位，已入场玩家在应用内点击“重新连接”恢复原席位。世界和个人数据由纯 C# 确认态恢复，Unity 只保存连接信息、提交操作和显示结果。

## 玩家行为与边界

- 空位未入场前没有可见角色，不碰撞、不受攻击，不参加救援、终局人数和全员失败判断。新成员获得本局初始个人装备，不补发此前收益；平台、商店、委托、敌人和世界进度继续。
- 已入场席位在房间生命周期内保留。断线解除自己的钓线并停止主动操作；实现者初值为身体继续留在世界，已有击退、伤害、倒地计时和自然恢复继续，队友可以救援。此危险策略尚非用户单独确认。
- 重连继承实际位置、生命、当前耐力和等待进度、钱包、背包、装备、商店与交易回执。断线期间自然发生的改变保留，不免费回岸、回血或补耐力，不重新抽货或重放未确认操作。重连不恢复旧钓线。
- 恢复凭据为房间与席位绑定的随机 32 字节密钥，Welcome 后即保留待确认凭据供显式重试；输入控制权仍须等统一激活帧。首次同步失败的席位仍可由新人取得并替换旧凭据，不会永久占位。普通日志和 HUD 不显示密钥。在线席位不可被另一个连接抢占；原连接尚未确认掉线时可稍后显式重试。
- 关闭应用不自动保存凭据；不提供账号、主机迁移或退出应用后的自动身份恢复。房主进程退出仍结束房间；房主本地玩家的连接中断时，独立房主服务继续。
- 终态拒绝新人，原成员仍能恢复查看。跨局离线身份在新局已经结束后回来时，不激活尚未出场的身体，不能逆转失败。重开等待当前在线成员，离线身份保留但旧局资源清空，回来进入新局；重开屏障期间掉线仍明确失败。

## 分层与同步限制

`ServerSession.TryBind` 为已停用的固定席位捕获非零帧 checkpoint，再分别发送快照与有界追帧；确认追上当前帧后才统一 Rebind。控制权 generation 严格递增，旧连接、旧 generation 和旧 epoch 无效。原框架默认仍要求完整绑定，部分名单与非零帧接入必须显式启用。

新连接的快照和补帧不进入已有玩家的共享发送背压。上限为 128 帧、10 秒及既有消息/字节预算；超过上限只撤销申请者，释放临时席位和缓存。房主到期帧尚未处理完时 `TryBind` 暂时返回 false，房间会在后续 Poll 继续尝试。首次未激活失败不永久占位，已入场身份则保留。

可靠 UDP 为握手保留独立的有界 2400 字节突发、12000 字节/秒额度，避免已有多客户端持续 ACK 让新握手饿死；仍受总带宽和数据报预算限制，未更改线上格式。

房间每轮发送前读取 `UdpNode.IsConnected`；连接进入关闭状态即停用，不能等可能被限流的 CloseAck 和最终资源释放事件才停止发帧。最终 Disconnected 通知仍保持资源已释放的原语义。

`RoomSeatRegistry` 管理身份和临时连接；`IslandHost/IslandClient` 管理协议、认证、重开和调度；`WaitingToJoin` 区分未出场与已出场掉线；控制器清理自己的待发操作，不影响其他玩家。恢复快照显示现有数据，不补播旧捕获奖励。

规则／状态／房间版本 **22**，状态头 **HISE**；输入 **10**、地图 **HIMF**。旧构建和存档明确拒绝，不提供迁移。

## 验证与复现

```sh
dotnet run --project tools/HookIsland.Tests -c Release -- --filter=recovery_
dotnet run --project tools/HookIsland.Restart.Tests -c Release
python3 scripts/run-island-party.py --app artifacts/live-room-recovery/HookPlatform.app --players 4 --recovery
python3 scripts/run-island-party.py --app artifacts/live-room-recovery/HookPlatform.app --players 4 --late-join
./scripts/verify.sh
```

当前已通过框架 148/148、UDP 31/31、恢复过滤器 17/17（含 3 项既有海域恢复测试）、重开 18/18，以及 Unity Editor 98/98。真实 UDP 覆盖 2／4 人正常捕鱼购买、实际关闭连接、恢复个人状态与回执、重复请求不二次扣费和恢复后继续捕鱼；终态恢复及离线身份回到新局也已通过。

原生验证和全量回归仍在执行，最终结果以 `artifacts/live-room-recovery/verification-summary.json` 为准。开发验收显式启用，使用正常输入取得收益与购买；仅为隔离恢复行为关闭敌人，不向运行状态注入资源。恢复和晚加入驱动受开发条件编译限制，不进入发布版。验证范围为本机 UDP，不等同于公网或跨电脑验收。
