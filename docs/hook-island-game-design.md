# 钩索小岛 · 核心玩法与循环

版本：0.1 · 2026-10-20  
类型：1–4 人合作钩索捕鱼游戏  
定位：轻松、热闹、容易上手；技术好的玩家有表现空间，朋友之间可以互相救场，也可以制造无伤大雅的麻烦。

本文是完整玩法设计提案。2026-10-20 的基础版已接入 1～4 人移动、出钩、跃鱼捕获与共享金币，试玩入口及实际范围见[联机基础版说明](hook-island-playable.md)。怪物、商店交易、成长和整蛊系统仍为设计内容。主题、钩索捕鱼、钩怪、宝箱与岛上商店来自既有构想；本文数值、关卡节奏及具体规则用于后续原型验证。

## 一句话介绍

四名玩家守着一座小岛，用可以钩中几乎所有东西的钩索，把海里的鱼、宝箱和麻烦一起拖上岸，赚够钱升级装备，合力钓起更大的家伙。

## 最值得先做出来的十秒

一条金色大鱼从海面跃出。两个人同时出钩，一个钩中鱼，另一个钩中了站在前面的朋友。被拖走的人把鱼拉向了错误方向，鱼掉在另一侧沙滩上，大家一起冲过去收鱼。此时，最后一个玩家又把一只螃蟹拖上了岛。

这个场景应该直接产生笑声。核心吸引力是**观察、预判、出钩、命中、拖回、现场变化**；升级系统负责延长这种乐趣。

## 核心操作

默认采用俯视斜角视角，让玩家看清岛上同伴与附近海面。原型先做键鼠操作，后续再适配手柄。

| 操作 | 作用 |
| --- | --- |
| WASD | 岛上移动，调整出钩位置 |
| 鼠标指向 | 瞄准钩索方向，显示落点或最大距离 |
| 左键 | 发射钩索；钩索命中第一个有效目标后开始回收 |
| 再按左键 | 提前松钩，处理拖错目标或危险情况 |
| E | 使用商店、交付重物、开启宝箱 |

钩索有明确的飞行速度、最大距离和回收时间，不会自动锁定鱼。出钩落空会损失一次机会，但等待应当短：普通出钩到可以再次操作，原型目标约 1.5–3 秒。

普通鱼在跃出水面的短窗口内可以被钩中。稀有鱼应有更明显的起跳预兆和更大的奖励，而不只是更短的反应时间。读懂水纹、背鳍和起跳方向，比乱点更有效。

钩到小型目标时自动回收，玩家可以缓慢移动。重型目标会拉住玩家，需要第二根钩索、调整站位或等待挣扎结束。先验证这一种双人协作，不同时加入复杂收线小游戏。

## 钩上来的三类东西

| 目标 | 主要乐趣 | 收获方式 | 风险或代价 |
| --- | --- | --- | --- |
| 鱼 | 看预兆、抢窗口、预判运动 | 拖到岸上后短暂挣扎，靠近即可自动收获 | 大鱼可能脱钩；站位错误可能让鱼滑回海里 |
| 宝箱与漂流物 | 发现机会、多人搬运、开出意外 | 小箱直接回收；大箱需要两人合钩后开启 | 稀有箱会漂走；重箱会占用钩索 |
| 海怪 | 主动选择风险，制造岛上混乱 | 钩上岸后利用冲撞硬直和钩索完成击败 | 会追人、打断收鱼，处理期间损失捕鱼时间 |

鱼和宝箱给玩家“我要出钩”的理由；海怪让玩家先考虑“现在适不适合把它拖上来”。

海怪必须有可识别的轮廓或预兆。玩家偶尔判断失误可以好笑，但不应反复把长得一样的目标当作随机惩罚。

原型海怪使用螃蟹：上岛后短暂预警，再朝最近玩家直线冲撞。撞到商店外墙会翻身；其他玩家此时可以钩住暴露部位，连续命中两次即可击败。普通状态的钩索只能拖偏、打断，不能靠原地无脑连点解决。

## 三层核心循环

### 每 5–15 秒：一次钩索机会

**观察海面 → 调整站位 → 预判出钩 → 拖回目标 → 收获或处理麻烦 → 转向下一次机会。**

海面应当持续提供可见目标。玩家落空后，可以立即发现另一个机会；等待下一条鱼不应成为主要体验。

命中需要明显的顿挫、绳索绷紧、目标反应和回收音效。落空也要看得懂：钩子从哪边擦过、是否被朋友或其他目标挡住，应当清楚。

### 每 2–4 分钟：赚钱并改变玩法

**选择容易赚钱的鱼或高风险目标 → 共同积累收益 → 回中央商店选一件强化 → 用新能力处理更难的目标。**

第一件明显改变钩索体验的升级，应在开局数分钟内获得。升级后，玩家要能立即感受到“我现在可以钩得更远／拖得更快／帮得上队友”。

商店保持中央、小占地、无需独立加载。打开商店时，角色停在安全交互区，不能被友方钩索拖走。购物不暂停全局；短暂刷新期用于集中讨论购买。

### 每局约 15–20 分钟：共同完成一个大目标

**开局捕鱼 → 完成委托、升级 → 迎来更大的鱼群和海怪 → 集齐巨物诱饵 → 四人合力捕获巨物 → 结算并选择下一局的打法。**

每局给出一个清晰的公共目标，例如“完成三份渔业委托，召来并捕获灯笼巨鱼”。诱饵通过委托获得，不从升级金币中扣除，避免团队为了终局目标一直不敢买装备。

终局巨物分阶段需要不同岸边位置合钩，迫使玩家移动和交流。单人模式下，相应减少同时需要的钩索数量。它是前面学过的预判、收线、救援和合钩的综合使用。

## 一局的初始节奏

以下时间是测试起点，不是固定承诺。鱼群和事件依照团队委托进度推进，避免新手尚未理解操作就被时间表推入高难度。

| 阶段 | 主要内容 | 希望产生的体验 |
| --- | --- | --- |
| 开局约 0–3 分钟 | 小鱼、低价漂流物，完成首次购买 | 每个人都能成功钩到东西，快速理解规则 |
| 中段约 3–8 分钟 | 跳跃方向不同的鱼、双人宝箱、第一只螃蟹 | 开始喊队友帮忙，分清收益与风险 |
| 升温约 8–14 分钟 | 稀有鱼群、同时出现的不同目标、第二轮升级 | 玩家形成临时分工，产生抢机会和互相救场 |
| 终局约 14–20 分钟 | 诱饵完成，巨物围岛活动 | 全队集中协作，得到一次共同完成的高潮 |

委托有多个可替代目标，例如“收获 6 条普通鱼或 2 条稀有鱼”，避免最后一条随机鱼迟迟不出现。普通鱼不会因为推进到后期就消失，新手始终有贡献途径。

## 合作怎么发生

合作来自同一件事里需要多人介入，而不只是在地图上各钓各的。

- **双人合钩：**重宝箱、大鱼可被多根绳索共同拉动。两名玩家要靠近同一段岸边；相反方向用力会降低效率，并以拉力箭头直观提示。
- **一人控怪、一人输出：**一个玩家诱导螃蟹冲撞，另一个玩家等待翻身窗口出钩。其余人可以继续捕鱼，或帮忙清场。
- **救回朋友：**落水玩家抓住浮圈，队友钩中即可迅速拉回；无人救援时约 5 秒后自动回到岸边。
- **临时分工：**擅长瞄准的人处理稀有鱼，拉力装备较强的人处理宝箱，喜欢冒险的人引怪。没有强制职业，升级可以换着试。

两个人以上参与的目标，系统明确标记协作贡献。奖励不归“最后一下命中的人”，避免队友在经济上争抢击杀。

## 整蛊怎么好笑，又不毁掉这一局

朋友可以被钩中，正在拖回的小鱼可以被截走，海怪也可以被拖向朋友附近。整蛊改变眼前几秒钟的局面，并给别人还手的机会。

采用以下默认边界：

- 友方钩索只产生短距离位移，不造成伤害、不直接把站在安全地面的队友拉下海。
- 被友方钩中后获得约 3 秒的抗重复拖拽保护；商店交互期间免疫友方拖拽。
- 鱼无论由谁收获，都进入公共奖励结算。截走鱼可以抢表现，但不能偷掉队友的升级收入。
- 落水不丢金币和永久装备；自动回岸确保单人或被冷落的玩家也能继续玩。
- 全队倒地时，清掉当前岛上的怪物并将玩家送回，损失当前未完成的大目标进度；不清空已经购买的升级。
- 房主可关闭“友方钩索”，让不喜欢整蛊的队伍正常合作。

整蛊不应比正常捕鱼更高效。如果最优策略变成不断钩队友，需要调整碰撞优先级、保护时间或位移幅度。

## 收益和成长

### 金币规则

每次收获产生两部分收益：约一半进入公共资金，另一半平均转化为每位玩家各自的装备额度。实际金额按人数缩放，保持相近的首次升级时间。

个人额度只能买自己的钩索装备；公共资金用于全队补给和岛屿功能。这样既能保证新手有钱买装备，也保留团队讨论的理由。公共资金在原型中只购买小额消耗品；高额建设留到后续再设计投票。

### 首批升级

| 升级 | 直接改变 | 取舍 |
| --- | --- | --- |
| 长线轴 | 钩索距离增加，能处理更远的目标 | 落空后回收更久 |
| 快速绞盘 | 回收速度更快 | 重物拉力不增加 |
| 重型钩 | 重鱼更难挣脱，合钩时贡献更大 | 钩子飞行速度较慢 |
| 倒刺钩 | 对翻身海怪的命中更有效 | 普通捕鱼收益不额外增加 |
| 分叉钩 | 末端分成两个钩头，扩大捕获范围 | 单个钩头拉力降低 |
| 救援线 | 救回落水队友更快，并给予短暂保护 | 占用一个功能装备槽 |

每人先设 **2 个钩索改装槽＋1 个功能槽**。商店允许低成本替换，不把一次不熟悉的选择锁死整局。单纯的数值加成少做；优先让升级改变可选目标和操作习惯。

首个版本不依赖长线数值养成。后续可增加鱼类图鉴、角色外观、钩索皮肤和新改装选项解锁；新老玩家一起玩时，不应因账号攻击力差距无法合作。

## 小岛和海面怎样服务玩法

中央商店是返回购买的定位点。沿岸保持连续、宽敞的出钩区域，低矮花草只做点缀；椰子树和码头提供辨认方向的地标。码头与沙岸直接连通，走上码头可接近外海目标，但玩家必须留意退路。

鱼群分布在多个岸边区域，并缓慢迁移。避免所有高收益目标长期只出现在码头，让其他海岸失去价值。起跳预兆通过水纹、背鳍、影子和声音表达；可钩窗口出现时再给出更清晰的提示。

玩家、目标与钩索需要高于装饰的视觉优先级。四条绳索用不同颜色区分；特效短而清楚，海面波纹和泡沫不能掩盖鱼的预兆。

## 失败、难度和人数适配

普通失败主要消耗时间与机会：钩空、鱼挣脱、被怪追走。不要让普通捕鱼频繁扣钱，否则玩家会倾向于站着不动。

难度优先来自目标组合、出现位置和协作需求，再考虑提高血量。1–4 人模式按人数调整目标数量、重物拉力门槛和巨物阶段要求；多人不应只变成同样的鱼有四倍血量。

同一局内，对已经明显落后的队伍延缓危险事件、补充普通鱼群。若一段时间内连续处理怪物，就让后续事件偏向收益机会，避免岛面一直无法恢复。

## 原型优先级

第一轮只验证钩索和朋友互动是否好玩：

1. 岛面移动、瞄准、出钩、收线和松钩。
2. 一种鱼的起跳预兆、可钩窗口、上岸收获与金币反馈。
3. 普通宝箱、双人重宝箱，以及一类可拖上岸的螃蟹。
4. 四人联机的目标归属、合钩、友方拖拽与救援。
5. 中央商店，以及长线轴、快速绞盘、重型钩三种升级。
6. 一条短委托链与简化巨物，形成可完成的整局。

前两项先在单机里调到手感清楚，再接多人。原型暂不做岛屿扩建、复杂制作、开放海域航行、装备词条库和永久数值养成。

钩索和目标的判定必须由统一的游戏状态决定，避免各客户端分别决定谁钩中了鱼。海面波纹、泡沫和装饰动画只是表现，不进入帧同步核心。

## 用试玩判断，而不只看功能是否齐全

首轮组织四人试玩，观察这些信号：

| 观察项 | 原型希望看到的结果 | 未达到时优先检查 |
| --- | --- | --- |
| 首次成功收鱼 | 新手约 30 秒内能完成一次 | 提示、鱼的轨迹、钩速与窗口 |
| 首次有感升级 | 开局约 2–3 分钟 | 目标密度、价格和回收节奏 |
| 主动交流 | 玩家自然喊出“帮我拉”“那边有大鱼”“救我” | 是否真的有值得合作的目标 |
| 整蛊反应 | 被钩的人能很快还手或继续玩 | 位移、控制时间和重复拖拽保护 |
| 目标可读性 | 玩家能说出一次失手的原因 | 镜头、遮挡、绳索颜色与海面特效 |
| 重复游玩意愿 | 结算后想试另一种钩索打法 | 升级差异、局内变化和终局高潮 |

最关键的验收是：**拿掉复杂成长，只留钩索、几种目标和四个朋友，十分钟内仍然能自然产生合作与笑点。** 如果这一点不成立，应先修正基础互动，再扩充内容。
