# 材料 99 堆叠与物品图标

日期：2026-10-27。应用于正式 `HookPlatform` 玩法。

## 材料规则

- 木材、鱼骨每个背包格最多 **99** 个，共用 `InventoryCatalog.MaterialStackLimit`。已有未满堆叠优先补齐，再占新格；100 个分为 99＋1。
- 拆分、合并、指定数量丢弃、拾取、满包溢出、建造扣料和快照验证均沿用同一个上限。一次丢弃支持 99；拆分必须保留原堆叠，因此最多拆 98。失败操作保持原状态，重试不重复转移。
- 地面材料包按种类和地块合并保存总量，不受单个背包格的 99 限制。拾取时仍受背包实际容量约束；剩余保留，不丢失材料。
- 资源产出、配方、价格和装备占格保持既有规则。

规则与房间协议版本升为 **26**，确定性规则标识为 `integer-mm-material-stack99-v26`。输入格式仍为 11、状态格式仍为 24；本次没有改变字段布局或地图格式。旧客户端在房间握手时被拒绝，避免不同堆叠规则共同结算。旧库存中每格不超过 20 的布局仍符合解码规则，但带旧规则清单的游戏检查点继续按既有兼容检查拒绝；本次不提供跨规则版本的存档迁移。

## 56 个原创图标

采用深蓝轮廓、暖色高光的航海卡通风格，透明背景，覆盖实际物品目录：木材、鱼骨、31 款钓竿、10 级背包、10 级泳圈，以及帽子、外套、鞋子。

- 木材以捆扎木料、鱼骨以鱼骨架识别。
- 六类钓竿使用不同颜色和特征标记，等级提升后增加护件和装饰。
- 背包逐级改变颜色、口袋、卷毯和随身工具；泳圈增加绳索、握把、指南针等细节。
- 背包与商店使用图片替代文字占位，保留等级角标和材料数量。旋转物品时图标跟随旋转且保持比例。名称和完整属性留在详情区。
- 同一套资源也用于角色装备槽、备用装备、拖拽图像和附近拾取列表。

源文件：`scripts/generate-item-icons.py`，延续项目现有 Pillow 图标制作流程，以原创绘图几何生成资源，无外部素材授权依赖。脚本读取物品配置中的稳定 ID，生成 `Resources/UI/ItemIcons.png` 与 `ItemIconMap.json`。图集为 1024×896、56 个 128×128 单元；3 倍超采样缩小，保留透明度，关闭 mipmap，Clamp 采样。每个图标的内容边界写入索引，避免长竿被横向拉宽。

运行时 `ItemIconCatalog` 只负责 ID 与图集区域映射，`ItemIconPainter` 只负责缩放、旋转和绘制。界面继续提交原有输入意图，不直接修改库存或钱包；图标不进入联机状态、回执或存档。

编辑器菜单 `Tools > Hook Island > Preview Item Icons` 可查看全目录；预览位于 Editor 程序集，不进入发布构建，不创建房间或注入资源。
