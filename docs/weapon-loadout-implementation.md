# 分类武器与单格库存

2026-11-04。正式工程为 `samples/TacticalGame.Unity`，场景为 `Assets/HookIsland/Scenes/HookPlatform.unity`。

## 当前规则

- 正式新局不赠钓竿，所有商人初始与后续补货均不再出售钓竿。底层钓鱼玩法保留，可通过 `FishingConfig.FishingRodsEnabled` 启用；正式 `FishingSettings.enableFishingRods` 为 false。
- 出生装备免费 Lv1 背包、满弹沙漠之鹰与平底锅，默认手持手枪。主武器栏初始为空，空栏切换不改变手持物。无钓竿加成时出生耐力为 100/100。
- **1 主武器、2 手枪、3 近战**，每类各装备一把。步枪与狙击枪共用主武器栏；数字切换只改变当前手持身份，三把武器仍在装备区，满背包也可以切换。
- **同类替换旧武器回背包**。从背包换上新武器时可复用它腾出的格子；直接购买或拾取并替换时，必须有空格容纳旧武器，否则装备、金币、库存与物品 ID 均不改变。仅玩家显式选择“放下旧装备”才落地，默认不勾选。
- 所有物品统一 **1×1 格**，包括枪械、近战、衣装、泳圈、空背包和兼容配置中的钓竿。堆叠上限不变：木材／鱼骨／实体子弹 99，保留的旧食品 5；非堆叠装备每格一件。金币和无限备用弹药仍不占格。
- 各级背包容量保持 64～288 格。穿戴物品不占背包；移动不再提供旋转按钮或 R 旋转提示。
- 装备页顶部三行武器栏显示当前手持，下方六个衣装栏。商店卡片保持可读图标和右上角价格，尺寸独立于实际库存占格。
- C 切视角，V 次数回血。4 投掷物未接入；正式界面不恢复旧的九格物品快捷栏。

## 状态、输入与事务

`InventoryState.ActiveItems` 保存每个玩家的手持物品 ID，身份必须属于本人已装备的武器或兼容钓竿。`WeaponLoadout` 统一槽位分类、失去当前物品后的回退顺序与换弹取消判定。衣装始终生效，手持工具属性仅在选中时生效。

`InventoryAction.SelectWeapon` 仍使用 24 字节库存命令，并明确校验主武器／手枪／近战三个目标，防止整数转 byte 后绕过检查。操作通过现有请求号与确认回执去重；失败请求不会在之后出现空格时自行执行，恢复检查点保留已结算结果。

弹匣随物品保存，切换不补弹、不重发装备。只有成功改变当前手持物才取消换弹；失败切换和选择当前武器不取消。出钩、近战动作等忙碌限制继续生效。射击、近战、角色外观、镜头、准星与弹药 HUD 都读取同一手持身份，收起的枪不能开火或装填。

Unity 控件和预览读取确认库存，操作只提交命令。角色页在满背包时仍允许切换已装备武器；单格商品只改变本地排版，购买仍使用确定性货架编号与批次。

本次版本为规则 40、输入 16、状态 35、房间协议 32，库存格式 BAG5。地图包含停发钓竿配置及最新目录哈希。沿用项目当前约定，不迁移不兼容旧档；拒绝旧客户端／旧档时不覆盖原文件。通用帧同步核心、传输与存档事务实现没有改动。
