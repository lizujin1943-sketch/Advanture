# 深渊凝视者模型视图

这些图片全部由同一个 Blender 模型实际渲染。原始外观依据为 `../cthulhu-octopus-boss-v1.png`；头型按用户最新要求改为乌贼式后倾长囊，并采用精细曲面制作。

- `model-overview.png`：模型整体及实际渔夫比例。
- `head-front.png`：头部正面，检查三眼与口器。
- `head-three-quarter.png`：头部侧前方，检查头冠、眼窝与礁壳贴合。
- `head-side.png`：头部侧面，检查后倾长囊的轮廓与厚度。
- `mouth-revision.png`：整改后的口部近景，便于确认唇褶、内腔和齿瓣方向。
- `front.png`、`back.png`、`left.png`、`right.png`、`top.png`、`bottom.png`：无海水遮挡的结构视图。

源文件：`source-assets/creatures/abyssal-watcher/AbyssalWatcher.blend`。用户已确认该模型，静态基线保存在 `AbyssalWatcher_ModelApproved.blend`。本轮动作范围和节奏见 [animation-design.md](animation-design.md)；动画预览及独立验证记录位于 `artifacts/abyssal-watcher/`。这些静态图本身不作为动画验证。
