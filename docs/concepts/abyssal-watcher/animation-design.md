# 深渊凝视者：第一版动作设计

2026-11-03，用户确认乌贼式头型，开始动作制作。本轮不设计、不制作抓住、卷起、举起或抛掷玩家的动作，也不制作玩家附着与解救演示。

## 整体感觉

身体固定在海中央，长头冠缓慢呼吸，八腕有不同步的小幅起伏。攻击体现巨型软体生物的重量：先清楚蓄力，再快速出招，接触后稍停，最后缓慢收回。正常战斗不移动 BOSS 根位置、不全身转向。以下时长是制作初值，后续可根据游玩手感调整。

| 动作 | 时长 | 可见过程 |
| --- | --- | --- |
| 登场 | 4 秒 | 从海下升起，八腕展开，眼光逐渐亮起，结束接入展示姿态。 |
| 普通待机 | 6 秒循环 | 头冠轻微呼吸，眼睛间歇闭合，触手错峰起伏；循环首尾衔接。 |
| 单腕下砸 × 4 | 3 秒 | 0～1.2 秒举腕蓄力，1.2～1.5 秒加速砸落，1.5 秒接触，停顿至 1.8 秒，随后收回。 |
| 单腕横扫 × 4 | 3.6 秒 | 0～1.2 秒低位后摆，1.2～2 秒扫过前方扇区，随后缓慢收回。 |
| 喷墨 | 3.2 秒 | 口器张开蓄力，1.2～1.8 秒向前喷吐，头部轻微后坐，然后闭口恢复。 |
| 受击 | 1 秒 | 头部短促后缩、恢复；幅度小，避免每次中弹都变成大硬直。 |
| 进入狂暴 | 3 秒 | 头冠震动，眼光增强，攻击腕抬高后落回更紧张的待机姿态。 |
| 狂暴待机 | 5 秒循环 | 呼吸、末梢起伏比普通状态明显，仍保留重量感。 |
| 单腕断离 × 8 | 2.6 秒 | 先短促回缩，0.3 秒断离，独立断肢翻落下沉；本体保留封闭残端。 |
| 死亡 | 6 秒 | 中止攻击，熄眼、垂头，剩余触手软落，随后整体沉海；已断腕不重新出现。 |

下砸的落点覆盖半径约 12～20 米的径向长条。实际地板破坏仍由后续游戏逻辑决定。横扫仅扫前方，不增加后四条支撑腕的攻击行为。喷墨的粒子只作为 Blender 方向与节奏示意，不是正式游戏特效。

## 分区与组合

- A01～A04 各有自己的下砸、横扫动作，单腕动作只写入该腕骨骼。
- 头部和口器单独控制，能和单腕动作组合；另做两腕攻击叠加喷墨的演示。
- S01～S04 只有待机、受击相关起伏、断离和死亡表现。
- 断肢演示采用独立对象，位置不再继承 BOSS；正式游戏中应在摧毁瞬间复制当前腕姿态。本轮的单腕断离片段从固定参考姿态演示。
- 腕是否仍存在，是独立于动画的状态掩码。更换待机、狂暴和死亡动作都不能恢复已断腕。

## 文件与查看

`AbyssalWatcher_ModelApproved.blend` 保留已确认的静态模型。动画保存在 `AbyssalWatcher.blend`，使用 30 帧/秒的制作时间线；这不是帧同步逻辑帧率。`exports/animation-manifest.json` 记录动作范围、事件时刻、控制分区与排除项。展示合集和单独片段均可播放。

这一版交付 Blender 动作与预览。正式战斗、伤害、平台破坏、墨汁危险区、运行时断肢以及 FBX/Unity 接入另行实施。眨眼与发光包含 Blender 驱动，后续游戏导出需烘焙或由表现层驱动。

验收包括真实骨骼运动、循环首尾、四腕覆盖范围、动作互不覆盖、断肢独立、残缺死亡、脸部连续控制、腕截面朝向及实际视频观察。合集在切段处使用 0.2 秒姿态过渡；单独片段保持原事件时刻。
