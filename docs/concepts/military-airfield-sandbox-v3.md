# 灰隼航空基地 V3：浓缩现实布局

2026-11-18。设计修订，尚未进入 Unity 白盒。替代 V2 的四角据点、中央操场和矩形围界布局；保留小型尸潮沙盒、战机、军营与四处可守可撤的空间。

## 修订依据

用户要求“不太方方正正、符合现实”“尽量浓缩参考现实军事基地布局”。本版继续使用 RAF Duxford 历史基地，优先保留功能之间的位置关系，并减少重复建筑和中间距离。没有把建筑随意旋转、把整张图改成蜿蜒迷宫。

核对的主要来源是南剑桥郡议会 2007 年历史评估草案：[公开 PDF](https://scambs.moderngov.co.uk/documents/s22365/Duxford%2520Airfield%2520Draft%2520Conservation%2520Area%2520Appraisal%2520without%2520maps.pdf)。重点参考印刷页 1、12–14、19、33–34。原型事实：生活区位于 A505 北侧、技术区位于南侧；营房与操场成组；仓储维修建筑靠近机库后方道路；多数建筑本来沿网格组织，部分外围建筑顺应机场前坪方向。以上是本版使用的历史功能关系，并非当代基地运行资料。

[官方保护区边界图](https://www.greatercambridgeplanning.org/media/j1xfagx0/duxford-airfield-conservation-area-boundary-map.pdf)已检索到，其保护区边界不能直接当作军用围栏或关卡边界。图像未完成可靠本地读取，本版没有据此描摹建筑轮廓、距离或地籍边线。作战楼和防爆设施另参照 [Historic England 建筑档案](https://historicengland.org.uk/listing/the-list/list-entry/1391608)。

## 浓缩方法

原型关系：**北侧营房和集合空间 → 中间道路 → 技术维修、仓储与作战楼 → 面向飞行区的机库 → 停机坪及场外跑道**。

- 北生活区缩成两栋营房、一间食堂和一个集合院。集合院移回营房组团，不再占全图中心。
- 保留中间道路的分区作用。现实中的 A505 公路在世界观中改成灾变后封锁、纳入隔离区的一段道路；这是明确的游戏改编。
- 维修间和军需库置于机库后方，飞机由朝向机坪的库门进出。两座机库沿同一飞行侧排列，大小与间距不同。
- 指挥楼放在南侧技术区，与营房分开；周围土堤借用原型建筑特征，游戏中的出口位置与可破坏规则须独立验证。
- 删除大多数重复机库、住宅和后勤建筑。保留一架约 17×12 米占地的虚构退役战机；完整跑道、其他营区和延伸道路进入场外远景。
- 外围采用营房围栏、技术区边界和机坪临时封锁线的组合，不再用一圈等宽环路和完整方墙包住所有建筑。地图轮廓来自不同功能地块的收放。
- 建筑仍保留可施工的直角形体和成组朝向；场坪边缘、道路汇入口、草地及后加设施形成不等距、不对称的空隙。图上统一偏转约 5° 只是示意构图，不宣称是实测方位。

本次候选范围约 **120×100 米（含外围接近带）**，比 V2 放宽，以容纳成组营房、两座机库和飞机前坪。压缩主要通过删减数量、缩短组团间距完成，不等比缩小飞机、车道与全部建筑。尺寸是白盒候选值，需用项目真实镜头、角色半径和尸群导航决定最终规模。

## 防守与转移

| 点位 | 来自哪种功能空间 | 防守收益与风险 | 两个主要转移方向 |
|---|---|---|---|
| A 东侧检查站 | 中间道路东入口，军车和岗亭 | 可以预见道路来袭；前后贯通，不能同时封住全部支路 | 沿道路向 C；南侧车道向 D |
| B 机库前坪 | 主机库门外与飞机东侧维修空地 | 机库挡住一侧，机身拆分视线；南方飞行区敞开，不能依赖飞机形成无敌位 | 机库之间向北上道路；沿停机坪向东到 D |
| C 营房集合院 | 两栋营房之间的小集合院 | 建筑提供遮挡，便于短时整备；北围栏破坏后不再安全 | 南口上道路；东口经生活区支路上道路 |
| D 作战指挥院 | 作战楼土堤外侧院地 | 北侧体块提供掩护；南机坪较暴露，需观察两翼 | 西侧穿技术区；东侧车道去 A |

四处是利用既有空间建立的临时据点，不把真实基地说成专为四点攻防设计。A 与 C 的两条支路都可能受中间道路敌群影响；B 与 D 共用开放机坪，因此不是四块互不影响的安全房。

进攻组织：东、西道路形成两种进场方向；飞行区宽正面提供大规模尸潮的主要展开空间；北侧营房围栏破坏只作为有预警的后期压力。每波选择主方向与副方向，沿可见外围接近；图中箭头是示例，不限制敌人只走一条线。营房后侧不应无预警刷新。

## 白盒落点与验收

示意局部坐标以偏转前的西北角为原点，米制候选值：主机库 (18,51)–(44,68)，次机库 (54,54)–(69,68)，飞机保守范围 (28,72)–(40,89)，指挥楼约 (79,43)–(94,53)。B 站位 (48,76)，C (38,25)，A (101,34)，D (87,59)。两机库间空隙约 10 米；它同时承担退路与技术区交通，需要验证是否被尸群占满。

最小验证依次检查：飞机能否从库门正面合理拖出；四点至少各有两条可理解的退出方向；道路战斗不会使全部跨区路线同时失效；飞机东侧能否看清追兵；南侧宽正面能否形成尸潮而不堵在一处；实际镜头下营房和指挥楼能否区分。
