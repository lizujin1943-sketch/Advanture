# 沉钟镇正式接入实施计划

目标：把已批准的水上小镇、沿线功能建筑、固定遭遇和大章鱼终局接入可游玩的确定性模拟与 Unity 场景。

依据：[小镇](../specs/2026-11-05-drowned-bell-town-design.md)、[终局](../specs/2026-11-05-drowned-bell-town-octopus-finale-design.md)。架构：不可变地图数据 + 可快照的镇区状态 + 已有战斗系统组合；Unity 只提交命令并表现确认状态。技术：纯 C# netstandard2.1、现有帧同步、Unity。

## Global Constraints

- 正式目录内原地工作，保留已有暂存改动；不自动提交。
- 镇模式只支付金币，旧模式兼容；木材和鱼骨不进入镇模式的产出、交易或界面。
- 主线与开战免费；C/E/F 解锁，所有在线活动玩家就位；可选服务按请求去重并原子结算。
- 敌人与 BOSS 状态、地板、弹药和回执必须进入快照与确定性哈希。旧存档明确拒绝。
- 十种现有敌人先完整接线，新增二十种保留为候选设计；最终战不刷杂兵。
- BOSS 八腕独立、四攻击腕、断肢不再生；只有指定木带可毁；失败免费复位，胜利只结算一次。
- 不把开发自动游玩注入正式发布场景。20～30 分钟与 BOSS 4～6 分钟是待实测目标。

## Review Focus

1. 旧地图与新地图边界、坐标、导航和三维命中使用同一套权威地形。
2. 重连、读档和重试不能重复扣费、领奖或领取尝试弹药。
3. 普通遭遇暂停保留血量与死亡回执，无玩家脚下生成。
4. 毁板不切断免费退路；金币为零、基础枪空弹仍可重新挑战。
5. Unity 入口真实可用，表现不能直接修改权威状态。
