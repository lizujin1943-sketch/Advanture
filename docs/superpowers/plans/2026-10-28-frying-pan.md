# 平底锅近战接入

目标：右手装备平底锅，左键朝瞄准方向挥击；键 1 / 2 从背包切换钓竿 / 平底锅。正式开局每人背包附送一口，商人可售卖补购。

- 配置：1.6 m、前方 120°、伤害 25、前摇 0.2 s、动作 0.6 s、间隔 0.8 s、耐力消耗 8。食人鱼生命 50，命中硬直 0.5 s；队友只击退 1.2 m，遵守房间整蛊开关与保护状态；水怪蓄力可打断。
- 攻击方向在起手时锁定，前摇结束仅结算一次；挥击时不能切换右手装备，倒地、受击、被钩或无游泳圈落水取消攻击。近战不生成钓鱼奖励、不增加或清空连击。
- 确定性规则、装备事务、输入、模型动画分别负责；沿用 Fire 输入与库存请求，不使用 Unity 碰撞回调结算。挥击、敌人受伤及硬直纳入检查点和兼容版本。

执行顺序：
1. 行为测试先覆盖装备、方向/距离、前摇/间隔/耐力、伤害/整蛊、取消与恢复。
2. 接入纯 C# 规则、库存、状态校验，运行规则与装备/战斗回归。
3. Unity 接入输入切换、持锅模型、挥击和命中声画、图标。
4. 四客户端 UDP 一致性及 Unity 编译、场景实玩和截图验收；记录验证边界。
