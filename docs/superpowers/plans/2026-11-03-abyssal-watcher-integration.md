# 深渊凝视者游戏接入实施计划

依据：[玩法设计](../specs/2026-11-03-abyssal-watcher-gameplay-design.md)。用户已确认接入现有钓鱼地图，作为可选挑战。

## 分工与顺序

1. **资产导出**：保留 Blender 已确认源文件，生成 Unity 模型、动作和材质，检查坐标、比例、片段、八条触手可独立控制，并提供整数碰撞代理数据。
2. **确定性玩法**：新增配置、状态、AI、攻击几何、毁板记录、奖励回执、状态编码；将其接入 `HookGame`，补齐专项测试和四客户端验证。
3. **Unity 与网络适配**：保留所有输入组合中的新增字段；增加唤醒入口、血条、预警、动作播放，显式安装到现有平台场景与地图配置。
4. **集成验收**：编译并检查 Unity 控制台，验证实际场景与攻击动作；运行相关游戏回归和四客户端一致性，记录尚未做的真人及跨系统验证。

资产导出与纯 C# 模拟可以并行，操作文件互不覆盖。Unity 场景操作集中在主任务，避免多个任务操作同一编辑器。

## 接口约定

- `HookState.Boss` 保存当前 BOSS 状态；禁用配置时为规范空状态。
- `HookInput` 在末尾增加上下瞄准分量和唤醒请求编号，所有输入缓冲与组合器必须保留字段。
- 战斗世界坐标中心为 `(0, 28000)` 毫米，前向为负 Z；Unity 使用米、Y 向上。
- 由模拟公开攻击区域及触手状态；表现层只读。资源安装脚本不启动游戏、不改模拟血量。
- 新功能不写入 `framework/`；自动验证逻辑只放在测试或显式开发验证入口。

## 完成记录

已完成现有地图的可选挑战接入。玩法、阅读顺序、运行方法和边界见[实现说明](../../abyssal-watcher-implementation.md)。

- `BossConfig / BossState / BossSystem / BossGeometry / BossStateCodec`：独立纯 C# 模拟、输入请求、三维命中、八条触手、毁板、奖励及保存恢复。
- `BossRequestBuffer` 和各输入组合器：唤醒重发去重、上下瞄准字段保留与事务互斥。
- `BossController / BossPresentation / BossAnimationView`：现有地图入口、UI、预警、模型动作和断肢。
- 正式场景仍为 `HookPlatform.unity`，地图导出字节与配置一致。没有向 `framework/` 加入游戏规则，也没有常驻自动游玩组件。
- 已批准的源模型保留，导出得到 44 个蒙皮网格、185 骨及 24 动作。Unity 导入骨链偏差 0.499 毫米，表情权重误差约 0.00000143；跨动作关节与主眼对齐检查通过。

### 验收边界

- BOSS 专项包含 19 个玩法／四 UDP 客户端检查及 6 个输入适配检查，覆盖毁板后的材料、落水、宝箱、螃蟹与终章位置协调，以及全灭冻结世界时钟、断肢退场和奖励去重。
- Unity：3 项 BOSS 表现检查、30 项原有相机检查通过；实际地图完成行走、唤醒、开枪、下砸毁板和喷墨，无运行异常。截图在 `artifacts/abyssal-watcher/integration/unity-play/`。
- 额外回归已通过：角色 28、游泳 29、敌人 45、近战 19、枪械 29、螃蟹 23、复活 37 项。
- 全量入口已执行框架、重放、网络及大量原有游戏检查，但没有完整跑到结束。原始日志保留在 `artifacts/abyssal-watcher/integration/full-verify.log`。按用户要求快速收尾，中止剩余长测，不能将本次描述为完整 `verify.sh` 全绿。
- 全量中发现两处验收工具问题：平台检查误拒绝鱼游入地格后的合法 `Occupied` 结果；宝箱自动输入的全队就绪门槛与个人到位门槛不一致。已修复验证工具而未改生产规则；平台 8 项及四 UDP 检查、宝箱 35 项及 1／2／4 UDP 检查通过。旧宝箱失败没有逐帧录制，因此不声称还原了其唯一触发帧。
- 未执行 Windows 实机、双 Unity 独立窗口完整 BOSS 战斗、真人平衡和专门 GPU 性能测试。数值仍是第一轮配置。

### 与初始计划的实现差异

- Blender 的骨骼继承缩放无法直接由 FBX 等价表达，游戏导出将单条触手的变形骨改为同级并烘焙世界姿态；源 `.blend` 保持不变。
- FBX 漏采的眨眼和张口权重由源动作清单重建为 Unity 曲线。
- AI 使用固定路线评分并优先分散正在攻击的目标，没有额外记录“上一条触手”来强制轮换。
- 毁板会在同一帧协调依赖地板的其他玩法，防止产生无法读取的自身快照。全灭时仅推进 BOSS 独立退场时钟，不推进商人和海域的世界时间。
