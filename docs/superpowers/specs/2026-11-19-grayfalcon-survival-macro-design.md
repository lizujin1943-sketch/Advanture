# 灰隼航空基地：持续生存宏观设计

日期：2026-11-19。版本：**V5，宏观设计草案**。用户已选定持续生存，并要求先确定大局，再展开据点细节。

本方案尚未搭建或试玩。[V4 局部设计](2026-11-19-small-airbase-sandbox-design.md)保留为参考；其中尺寸、站位和射线尚未锁定，不代表 V5 已通过验证。交互图以 V4 候选几何展示总体关系与据点细节，广播菱形仅表示提议位置，未计入实体碰撞或实现游戏机制。

## 体验目标与边界

玩家在小型废弃军事航空基地中持续生存：观察局势，选择有利据点，抵御尸群，再根据来敌方向与退路状态决定留守、主动改变局面或转移。

以 **84×62 米**包络作为首轮白盒起点，保留营房夹院、机库、军需仓、军事操场和战机机坪。该尺寸是测试起点，后续由实际移动、视距与追击决定调整，不为保住旧坐标牺牲路线选择。

备用弹药无限。地图不靠强制搜弹、强制跑腿、必做任务或固定失守倒计时推动移动；换弹、敌人接近、侧口压力和空间控制仍需按正式玩法验证。没有“守够时间必定失败”的规则。

## 三角关系与区域用途

三处据点构成互相连接的三角关系，每处至少能联系另外两处。连线表示可选择的关系，不规定固定 A→B→C 顺序，也不保证所有连接随时安全。

```text
        A 营房夹院 ── 操场短路／外围绕路 ── C 军需仓
             ╲                                 ╱
          前口近路／西巷                 机身两侧路线
                 ╲                         ╱
                           B 机库
```

| 空间 | 宏观作用 | 玩家需要判断的取舍 |
| --- | --- | --- |
| 三处据点 | 整理队形、集中火力、暂时控制附近入口，并接应转移者 | 当前容易守住的方向，可能正好暴露下一次撤退口 |
| 操场 | A 与 C 之间视野较开阔的短路，也是观察与交火空间 | 省下路程，但横穿更暴露；据点被压时仍可能值得冒险 |
| 外围绕路 | 提供较长、局部遮挡的转移选择 | 遮挡也会藏住敌人，绕远还可能让目的地先被占领 |
| 战机机坪 | 让 B 与 C 之间能够从机身不同侧面通过 | 根据道路侧与南侧压力选路，两个分支仍共用建筑侧后口 |

外围不是安全闭环。敌人也应使用真实可达的短路、建筑开口和连接口抄近路；不能把整片尸群限制为只沿玩家身后的同一条长路追赶。必要的遮挡与转角需同时支持玩家判断和敌人导航。

## 持续生存的局势循环

**观察选点 → 防守 → 主动改变局面或转移 → 再占据点 → 重新观察。** 这是反复作出的判断，不是阶段锁定或自动推进的任务链。

1. **观察选点**：根据可见尸群、外围接近信号、出口和目的地情况，选择当前更有利的据点或接近路线。
2. **防守**：集中火力争取局部优势，同时留意侧口、伤员和退路；有效防守可以继续，不强迫玩家无理由离开。
3. **主动改变局面**：通过走位引导部分追兵、调整队员位置，或让队友先接近下一点再接应；这些收益必须由正式寻敌与追击规则验证。
4. **转移与再占据**：带着尚未解决的追兵离开，确认新地点是否已被占领，再清出入口并重新组织防线。

撤离不会重置旧局势：留在原据点的尸群继续存在，追击者沿合法路线追赶，目标据点可能仍有敌人。进入新据点不自动清场、刷新安全或取消追踪；回到旧据点同样需要重新判断。

多人可以轮换观察、吸引追兵、抢先占点和接应职责，不指定永久职业。分人行动会减少原防线火力，也可能使先到者孤立，收益不能没有代价。单人仍须能通过观察和路线选择完成转移，不要求有人同时守后或启动机关。

## 三个外围压力方向

| 方向 | 主要影响 | 可能改变的选择 |
| --- | --- | --- |
| 西侧来敌 | A 西后口、A—B 西巷跨路段、B 北门 | A 的后撤预案可能受阻，B 也未必适合作为接收点 |
| 东侧来敌 | A 东正口、操场接近面、C 西口 | A 与 C 可能同时受压，操场短路与外围绕行的价值改变 |
| 南侧来敌 | B 东后口、C 南后口、机坪两侧路线 | B—C 转移可能被截断，不能把侧后口当作永久安全出口 |

外围压力应能提前读到，例如真实可见的接近者、入口处的声响或尘土动静；具体表现另行验证。增援使用合法外围位置和真实入场路径，禁止在玩家脚边、已清楚观察的室内或退路上凭空生成敌人来强制失守。

## 唯一可选新机制：操场边诱敌广播

在操场边提出一个可选广播启动点，用来短暂改变附近尸群的注意方向。只影响范围内尚未贴身交战的敌人，不作为全图强制转向或必做目标；敌人仍沿真实可达路线移动，不传送、不清场。

启动声音会暴露启动位置，使用者要承担接近操场、停留启动和撤离的风险。它可以给队伍制造转移机会，也可能把更多敌人引到自己接下来需要经过的区域。单人使用也必须有可辨识的代价和退出机会。

影响范围、持续时间、冷却、启动耗时与目标切换细则均待测。不开广播时，三据点、观察、追击与转移的基础图也必须成立；本轮不再增加门控、电网或其他机关。

## 先验证三个宏观场景

| 场景 | 观察问题 | 优先调整 |
| --- | --- | --- |
| 变更主要来敌方向 | 西、东、南压力变化后，玩家是否改变据点、朝向或转移路线，并能说明理由 | 入口关系、视线、路程与侧口暴露 |
| 分人引怪与抢点 | 是否能为队伍创造机会；是否同时付出火力减少、队伍分散或先到者孤立的代价 | 追击逻辑、接应视线、据点间距；再单独比较广播开关 |
| 长期守一点与固定跑圈 | 两种做法是否稳定压过观察、抢点和转移；敌人能否利用真实短路形成可读压力 | 开口、导航、短路与压力配置；不靠突然刷怪或强制倒计时纠正 |

每个场景都先验证不使用广播的单人和多人体验，再增加广播进行对比。记录玩家选择、转移理由、追击路径和被困位置；路径连通或脚本通过不能代替真实游玩证据。

宏观关系成立后，再确定 A 的两翼夹射、B 的纵深后撤、C 的折角近战是否适合各自位置，并细化站位、射击方向、掩体尺寸和退路净宽。V4 的局部方案可调整，不提前锁死。
