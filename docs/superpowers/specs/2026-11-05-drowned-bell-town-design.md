# 沉钟镇：水上克苏鲁小镇地图设计

日期：2026-11-05。状态：设计稿，尚未制作白盒、修改场景或调整经济代码。

## 1. 已确定的需求

- 更大的水陆结合地图，整体为建在海面上的克苏鲁风格小镇。
- 一轮完整探索目标为 20～30 分钟；沿用岛上探索、枪械战斗的方向。
- 功能建筑沿探索路线分布，至少 10 种，数量可增加。大部分在门口使用，少数关键建筑可进入。
- 取消木材、鱼骨及其货币、配方、升级用途，主要经济行为统一使用金币。
- 优先设计战斗发生的空间、怪物的刷出位置和入场路线，再布置建筑。

以下是本稿的设计选择，尚待白盒验证：1～4 人合作；12 种功能建筑；7 个主遭遇区；固定海平面；单层可行走空间。主线不依赖船、跳跃、多层攀爬或动态潮汐。

## 2. 体验和地图形状

玩家从南侧归航码头进入，沿环镇栈道探索不同街区，在广场、货场、水庭和档案前庭作战。恢复三个镇潮节点后，经中央礼拜堂进入沉钟祭港，击败关底大章鱼「深渊凝视者」，回到码头结算。

全镇建议包络 **160 × 128 米**，由架空街屋、少量岩基、木石栈台和水道组成；俯视占地约六成以上为水域，实际行进和战斗主要发生在连续的干燥街面。该比例是视觉方向，不是精确面积指标。海水穿进街区，建筑之间能看见桩基、船底和水中遗迹，避免变成普通陆地地图外围加一圈海。

环镇街道始终可步行。中心礼拜堂有一条常开入口，另有修复捷径；短水道可省路，但没有必须游过的主线关卡。钟塔、机房排气塔、归航码头灯架形成三个远距离地标。

三条设计支柱：

1. **从交战空间组织街区**：每个广场有明确威胁方向、可用掩体和退出方向；建筑门面服务这些空间。
2. **水带来路线取舍**：较远的干燥栈道、付费修复的桥和短距离游泳分别付出路程、金币与体力／生命成本。
3. **沿途整备再前进**：功能点分散到行进路线上，已经走过的街道不持续随机刷怪，减少补给路上的重复清场。

## 3. 路线、目标与节奏

建议首轮路线：

`01 归航码头 → A 港口卸货场 → 02 军火铺 → 03 诊所 → B 断帆广场 → 04 船具店 → C 工坊货场 / 05 工坊 → 06 委托所 → 07 当铺 → D 沉水集市 / 08 测绘站 → E 双闸水庭 / 09 机房 → 10 驿站 → F 档案前庭 / 11 档案馆 → 12 礼拜堂 → G 沉钟祭港 → 01 码头`

顺时针路线用于初次引导，不强制按编号过门。南岸街道连接档案馆一侧与码头，构成外围大环；玩家可以反向探索。三个必要节点分别在 C 货场、E 水庭和 F 档案前庭：恢复外港供能、启动镇潮闸机、解读仪式记录。节点均免费；清理对应主遭遇后可操作。它们是本局任务状态，不是新增材料或可消费货币。集齐三个状态后才可主动启动 G。

| 阶段 | 目标时间 | 玩家行为与信息 |
| --- | --- | --- |
| 港口与西街 A、B | 4～6 分钟 | 整备，识别近战前摇和冲锋，发现环镇路线与中央钟塔 |
| 北街 C、D | 6～8 分钟 | 对付护甲／治疗与远程封路，恢复供能，选择支路与补给 |
| 东岸 E、F | 6～8 分钟 | 处理岸边牵引和孵化，开闸、登记驿站、取得仪式解法 |
| 礼拜堂整备、祭港 G 与返回 | 4～8 分钟 | 大章鱼战斗目标 4～6 分钟，解除仪式，经回程桥返回码头 |

时间是首次常规探索的设计目标，不是现有怪物数值已经达到的时长。建议主路加局部探索约 550～700 米；当前 3 米/秒的陆地速度意味着纯移动约 3～4 分钟，其余时间必须来自有意义的战斗、探索和整备。若实测过短，先补有选择的侧路遭遇；不靠空走、强制等待或单纯加血拖长时间。

A～F 共 18 个普通候选入场口，G 使用独立 BOSS 入场。不是让每个普通刷怪口都同时出怪。每个口至少有一个绕遮挡后进入广场的有效路径；门口、登陆口和侧巷的美术形状对应不同的入场方式。

敌人扩展池见 [新增二十种候选与战区替换方案](2026-11-05-drowned-bell-town-expanded-bestiary-design.md)。它在已有十种之外补充 M11～M30 的实体弹道、掩体攻防、有限报警、近岸拦截与精英机制；新增种类按固定遭遇包轮换，每局目标 8～12 种，替换原编队槽位，不额外增加同时在场数量。A～F 原表仍作为基础编排，扩展敌人尚未实现；M29／M30 不再替代大章鱼终局。

### 触发与出生规则

- 主要遭遇使用地图编排，替换本地图当前“计时后在玩家附近轮转出现”的通用生成方式。后者不能与区域编排同时运行。
- 进入广场外沿约 8m 的预告带时播放环境线索；第一名非倒地玩家跨入内沿，且仍有成人名额时启动该区域。路线交汇处不同时触发两个区域。
- 候选口必须有地面／水域合法性、通向交战区的路径，并与所有玩家至少相距 8m；主要使用建筑实体遮挡住的出生位，敌人再经过可见出口入场。检查来自确定性地图和确认态玩家位置，不依赖 Unity 相机或 Physics。
- 每次入场至少 1.5 秒可感知预兆，来源可用门后撞击、脚步、涌水和出口标记。预兆期间不会造成伤害。批次内各口可错开 1～2 秒。
- 如果玩家堵住候选口，尝试该区其他已标注口；全部不合法就延后，不在脚下、柜台旁或玩家背后强行生成。
- 全图成人同时上限沿用 4；普通遭遇以 2～3 成人为主，母巢最多 4 幼体另计。最多同时启动两个普通遭遇，按触发 tick、区域编号稳定排序，空槽先满足每个活动区的第一个成人，再补第二、第三个；现有敌人不为重新分配而消失。槽位不足时同区其余敌人延后入场。G 启动前须先暂停其他已无交战玩家的区域；仍有人交战则提示等待。
- 交战占用只由未倒地、未购物且在区域及外沿 8m 内的玩家维持。原遭遇所有交战玩家离区超过 12 秒后回收存活单位；若区内只剩倒地者，另给 12 秒救援缓冲后回收。暂停菜单不维持占用；一名挂机者至多占住一处普通遭遇，队友仍可在另一处推进。两个活动区已有真人交战时，第三处只预告。
- 回收不等于清场。保存存活敌人的生命、类型、槽位、母巢已用孵化次数、存活幼体的生命、已清批次和金币收据；清除未命中的攻击与地面毒区。重新进入时先给入场预兆，再进入完整恢复／冷却阶段，不恢复生命或孵化额度。幼体按全局 4 个名额逐个恢复。已击杀槽位不补、不重发金币。主遭遇清场后本局不自动刷新。自由巡逻首版不额外叠加。
- 终局在三个必要节点齐备、在线活动成员于祭港确认就位后主动启动。始终可原路退出。G 使用专稿的 BOSS 尝试规则：无人可战斗满10秒后整场复位，免费重试，保留镇区进度；不套用普通区12秒残血回收。
- 四人分散时共享同一个遭遇调度与上限，不按每人复制整队敌人。倒地、离线、重连不会重置遭遇奖励。
- 大章鱼完成死亡状态时一次性提交本局胜利、BOSS奖励和回程桥状态。返回码头由房主发起结束探索提示，所有在线玩家（包括倒地者）确认后返回房间；无需强制其他人立刻赶到码头。未确认则继续探索，离线者不参与投票，重连读取已经结算的局状态。单人直接确认。普通回码头补给不会结束本局。

### 转场与掩体尺度

- 主街／主栈桥建议 5～6m，侧巷 3～4m；窄桥只承担短距离转场，桥两端各有至少 8×8m 整队落脚台。
- 主战场的有效侧移带不少于 4m；冲锋直线段建议 12～18m，两端不直接接水边。
- 枪械当前射程为手枪 12m、AK47 24m、AWM 40m、巴雷特 50m；主要战场控制在约 10～24m 的有效交火距离，个别 30～40m 的远眺口作为可选狙击收益。实体建筑截断跨全镇射线。
- 矮栏杆、布棚、雾气只作美术和提示，不能假称能挡子弹；战术掩体必须导出到确定性实体数据，同时影响子弹、敌方视线、手雷和导航。
- 功能建筑门口与主要技能落点分开；买卖菜单在附近仍有敌对单位或伤害预警时不能打开。商店不提供可攻击敌人但敌人无法靠近的无敌射击点。

## 6. 水路、桥与回程

- 外围大环、11→12 的礼拜堂入口桥均常开、免费。
- **捷径 S1**：西街 B 附近连接 C 南侧货场，绕过一段曲折背街；由机房花金币维修，适合回访军火铺／诊所。
- **捷径 S2**：北街 C 南侧连接中央礼拜堂北入口；由机房花金币维修，缩短北街与终局区域之间的往返。
- **回程 R**：击败大章鱼、仪式解除后，祭港西南侧的检修桥免费展开，连接起点码头。属于通关反馈，不是付费主线门。
- 两处游泳切口分别贴近船具店和东岸支巷，每次实际涉水距离建议 4～6m。两端都有低台与清楚的上岸提示；海面装饰不伪装成可站立的平台。
- 当前基础游速 1m/s，未带泳圈每秒损失最大生命的 1%，主动游泳消耗体力。6m 横渡约 6 秒，约 6% 最大生命损失且有明显体力成本；不让玩家一次强制游几十米。无泳圈时不能维持枪械操作，不能把水路当作与陆路等价的战斗通道。
- 狭窄转场桥的 10m 邻域不设置牵引怪出生口。水中跌落后须能在约 6m 内找到合法低台，不只在表现层放梯子。

## 7. 金币经济及木材／鱼骨退场

本节属于待实施的经济变更范围，设计文档不会自动改变现有资源规则。

- 金币是唯一支付资源。枪弹、治疗、泳圈、手雷、付费复活、桥梁维修均用金币。
- 取消木材／鱼骨余额、相应掉落、材料槽、双配方铺地、材料升级与鱼骨专属玩法加成；不把旧材料换名成两种代币。木栈桥、骨质装饰可保留为美术，不提供资源效果。
- 新地图首版只开放指定捷径与 BOSS 四条木带的金币维修，不开放任意铺地改变主线地形。后续若保留平台模式自由建造，改为金币配方，材质不再形成两套经济。
- 金币来源：敌人死亡奖励、可选委托、少量一次性金币藏点、出售多余装备。主遭遇死亡奖励与一次性藏点都有稳定收据，不因退出区域、读档、重连而重复发放。
- 武器、弹药、泳圈与复活首先沿用现有商品／复活定价，不在地图设计中同时重做整个数值体系。新增治疗和桥费使用配置，白盒初值可先用治疗 40 金币、S1 60、S2 80，全部标记为待平衡。
- 对外港第一段的验收要求：初始金币、基础武器与弹药能通过 A、B，不需要钓鱼或反复刷钱。现有初始 3000 金币是联调值，不能直接作为本地图经济平衡结论；最终起始包在经济验收时确定。
- 为避免金币和弹药双空造成硬锁，每人保留一把不可出售的基础手枪和基础近战。军火铺及已登记驿站在“所有可用弹药为零，且金币不足购买一份基础弹药”时可免费补 7 发基础弹，每人冷却 90 秒；基础弹药不允许出售，冷却保存到本局权威状态，重连不刷新。该兜底需要新接入，不能声称现有系统已具备。普通街区节奏仍应由起始包和途中收入维持，验收不把等待免费补弹当作正常流程。BOSS 单次完整重试所需火力另按关底专稿提供有限、不可带离的尝试弹池，避免7发补给与满血重置互相卡死。
- 必要节点、档案解读、终局启动与返回结算免费。余额为零仍有合法主线路线。消费界面明确显示个人支付与本轮共享桥效果，首版不自动扣队友的钱。
- 维修、购买、出售、治疗和委托发奖按请求 ID 去重；验证余额、扣除金币和产出／效果在同一权威事务完成。失败请求不隐式重试，不先扣钱再等动画回调生成结果。
- 旧存档有材料余额／木骨地格类型；实施时升级经济／地图兼容版本并明确拒绝旧版本，首版不静默换算旧资产。若将来要迁移，再制定固定换算与已结算记录保留方案。

## 8. 当前工程边界和实现顺序

已读取当前 `IslandMap`、`PlatformRules`、`SwimmingTerrain`、`SwimmingSystem`、`FirearmRules`、`GrenadeRules`、`CrabNavigation` 与新敌人实现文档，以下均为代码证据，不表示新地图已实现：

- 陆地基础速度 3m/s；基础游速 1m/s，未带泳圈每秒扣 1% 最大生命；枪械使用一人称镜头，默认垂直视野角 65°。尺寸须同时以持枪视角和原探索视角检查。
- 当前地图点坐标限制约 ±50m，敌人约 ±49m；建造网格 2m，坐标 ±24 格，最多 512 地格。160×128m 的新镇超出当前容量。
- 平台模式的可站立区域来自可变地格，不能只绘制新的 Shore 轮廓就得到新城镇；当前单个岸线多边形／码头也不足以表达多街区、多水洞布局。
- 地图实体遮挡目前主要针对商人台和少量固定岩体。新增房屋、巷道、掩体与室内必须导出同一份确定性障碍数据；Unity Collider 不能独立决定权威命中和通行。
- 当前新敌人为时间轮转、玩家附近生成。区域触发、编队、固定入口、一次性清场、驿站落点、地图标记和金币桥均需要新接入。

建议实施分四个可独立验收的阶段：

1. **地形与关键战斗白盒**：先做 A、B、E、G 四个小测试片段；确认通行、掩体、视线和跌落上岸。为静态地面建立不可拆卸地图数据，与最多 512 个可变建造格分开；扩容统一世界边界，检查所有状态编码、投掷物和导航处的旧常量。
2. **整镇动线与遭遇编排**：连接七个战斗区，建立不可变地图内容与权威遭遇状态；固定出生口、触发、脱战、名额、清场与防重结算。暂停本地图原计时生成器，先不堆完整美术。
3. **金币统一与建筑服务**：移除木骨经济，按同一事务接口接十二种建筑；其中商品种类可复用现有库存，地图目标、捷径和驿站另建本局状态。所有共享变化来自确认命令，不来自 Unity 显示／预览。
4. **美术、提示与调优**：加入海面、架空桩基、封闭屋顶、雾与音效；可进入房间只做单层。反复检查视线和上岸点没有被装饰破坏，再做 1～4 人节奏与经济平衡。

开放给制作人员决定：单栋屋顶、门窗和小巷的精确造型；符合净空与出生规则的刷怪口微调；白盒实测后的治疗／桥费。改变七处遭遇职责、取消免费主线或增加强制游泳需要重新评估本方案。
