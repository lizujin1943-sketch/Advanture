# 沉钟镇敌人扩展：新增二十种候选

日期：2026-11-05。状态：设计稿；下列二十种尚未实现，不包含在当前 `EldritchCatalog` 的十种可战斗敌人中。

## 1. 目标与取舍

依据用户要求：怪物类型不足时可再设计二十种；应优先考虑战斗在哪里发生、怪物从哪里出来。沿用水上克苏鲁小镇、探索与枪械战斗、1～4 人合作、金币经济，以及地图稿的 A～G 七个战区。

现有十种已覆盖贴身追击、冲锋、正面护甲、锁线光束、岸边牵引、持续毒区、治疗、孵化、闪现和环形震波。它们足以启动地图白盒；新二十种补充实体弹道、掩体攻防、有限报警、陷阱、近岸拦截、声音追踪和精英协同，使各街区能通过行为组合产生区别。

新增编号使用 **M11～M30**，避免与地图建筑 01～12 混淆。它们构成扩展池，不要求一轮 20～30 分钟内全部出现。每局以 8～12 种为目标；首次白盒先测试 M11、M17，再按独立验证结果加入其他类型。编号是设计编号，尚不是网络枚举值。

设计规则：

- 每种有明确轮廓、可感知预兆、普通枪械可用的反制与适合的空间；不要求付费技能、钓竿、理智值、强制游泳或玩家跳跃。
- 主要威胁仍在街面，水生敌人从近岸威胁陆地玩家。新增怪物不偷金币、不扣永久装备、不关闭整片 UI。
- 新敌人优先替换原编队相近职责的槽位。全图 4 个成人、最多 4 个召唤幼体，以及最多两处普通遭遇并行的边界维持不变。
- 新怪的攻击物、护符、墙体是有上限的效果对象，不伪装成无限数量的召唤单位。

下表中的前摇、距离与数量是待白盒检验的初值，不能作为已平衡数值。默认攻击有至少 1.5 秒入场预兆；入场之后每次攻击另有自己的预兆。所有敌人均能被基础枪械伤害，特殊反制提高效率而不构成付费装备门槛。

## 3. 给七个战区配置变体

这些变体替换原表的一批敌人，保持原有刷怪口、目标、清场条件和通路；不是在原编队上继续叠加。替换在开局确定，不能到半场因玩家买了某种武器而偷偷改成克制阵容。

| 战区 | 原稿职责 | 首选扩展变体 | 首次教学与限制 |
| --- | --- | --- | --- |
| **A 港口** | 教会近战前摇和射线躲避 | 眷属先入场；第二批用 **M11 投矛者** 替换观测者 | 单独看清一支矛的飞行，再进入组合。M16 / M20 只用于可选凹室，互斥 |
| **B 断帆广场** | 冲锋横移与断船绕行 | **M13 拖行者＋眷属** 替换奔兽组合 | 不同时放奔兽。M22 / M25 / M26 是另外三种替换版本，每次最多选一种特殊机制 |
| **C 工坊货场** | 绕背与支援优先级 | 熟悉编排可用守卫＋**M17 书记**；或眷属＋**M18 缝合师** | 首次编排 C 保留原表，先让玩家在 D 单独认识书记。缝合师版本先单独展示符印再加入眷属；不用守卫＋缝合师。M14 / M27 / M28 分属独立后续变体 |
| **D 沉水集市** | 远程压迫、封路与换掩体 | 先单独一名 **M17 书记**，清场后再用 **M11 投矛者＋M17 书记＋眷属** | 第一阶段只加入这两个新种类。投矛者已在 A 教学，书记在 D 第一批教学。M12、M15、M19、M28 以后轮换其中一种，不把散射、雾、地雷和墙堆在同一场 |
| **E 双闸水庭** | 近岸风险与向内陆退避 | **M21 镰鳍＋眷属**；或 **M23 海葵＋眷属** | 两种水生互斥，替换溺钟和行者组合；保留完整干地与可用低台，不强制跳海追杀 |
| **F 档案前庭** | 接近后排、打断与清幼体 | **M24 执事＋M25 双刃徒**；或母巢＋**M17 书记** | 第一种先学带走咒印，第二种仍以母巢为目标。M14 不与 M24 / M25 组队，缝合师不与治疗组队 |
| **G 沉钟祭港** | 大章鱼专属关底 | 固定为「深渊凝视者」，不加入本表新种类 | 见 [关底专稿](2026-11-05-drowned-bell-town-octopus-finale-design.md)。M29／M30 仅保留为另行设计的可选精英，不作为前置消耗波或最终替换 |

开局的基础编排保留地图稿已定义的种类；进入扩展编排时，根据固定遭遇包选择 8～12 种，至少保留基础眷属与一种清楚的远程威胁。新的机制首次出现时单独展示，之后才组合；主线新增专有机制每个街区至多一种。M11 可先在 A 教学，M17 可先在 D 教学，再用于后续区域。

M20 的凹室应在主广场侧面、与柜台错开；M19 的陷阱侧路仍有不付费干地可绕。额外支路遭遇计入最多两处活动遭遇与成人槽位，不额外开第三套刷怪系统。

## 4. 出生、攻击与对象预算

- 运行时出生复用地图稿的固定候选口、所有玩家至少 8m 距离、可达性与实体遮挡检查。M22 台下预兆和 M29 双入口遵守该规则；M20 预放休眠体的揭露是下述明确例外，不等于运行时出生。
- 门、巷和台缘的预兆必须先可感知，怪物再取得伤害能力。所有普通出生口被玩家占住时等待，不把位置移到玩家背后。
- **M20 的名额和距离**：每局至多选择一个寄箱凹室，开局即固定休眠箱的位置与可观察外形；凹室不承担主线交通。凹室遭遇先申请一个成人槽位，成功后休眠体立即占槽，再开放射击与接近揭露。槽位未获配前铁锁闭合、可观察但不可搜刮，不产生伤害或奖励。接近 3m 的揭露不再检查 8m 距离，因为单位没有临时出生或换位置；仍保留 1.5 秒攻击前预警。先手射击可以对已获配槽位的休眠体造成伤害并揭露，击杀则正常去重结算。脱战释放槽位时保存其剩余生命和揭露状态，回收规则与其他敌人一致。
- 图稿中的出生口只有位置与接近方向；沉船、岗亭和书库等外形在制作时须放置真实可通行的出口，不允许模型在墙内生成后穿过障碍。
- 地面怪沿同一份确定性地图导航；水生怪保持水域占位。不能通过 Unity 动画位移把怪物移上无地面或穿过商店。
- M11、M12、M17 的飞行物命中实体即结束，不能穿过掩体后继续命中；M13 出锚／回锚分别计命中，合并时不能多帧重复伤害。
- M14 减速同类不叠加，不禁用转向、开火、换弹或救援。减速与其他移速效果合并后保留至少 60% 基础移动速度；先按乘法合并再应用底线。
- **效果硬上限初值**：全图敌方普通飞行物 24；M23 爆卵全图 6、单只 3；M19 孢雷全图 4、单只 2；M28 盐墙全图 2、单只 1；M18 符印全图 2、单只 1；M15 雾幕全图 2、单只 1；M30 钟印全图 2。超限时等待，不删除另一个施法者已经产生的效果。
- 飞矛、潮泡、绳结、符印、爆卵、地雷、盐墙、钟印均有稳定来源与序号，不能靠客户端粒子碰撞决定伤害。击毁攻击物、假目标或墙不发金币。
- 敌方攻击和爆卵爆裂默认只伤玩家，不产生玩家主动引爆造成的队友伤害；击毁未爆卵只销毁该攻击物，不额外爆炸。需要怪物互伤的玩法另行设计，不从粒子爆炸推导。
- 精英 M29 按两个成人身体占两槽，始终一次结算。M30 本体占一成人槽，钟印是两个可破坏效果对象；两个精英均不增加新的召唤名额。
- M29 必须同时验证两个合法入口并一次性预留两个人口槽，再同帧生成两个躯体。任一入口／名额不合法则整组延后，不先生成半个精英。两个躯体各自展示入场预兆，共享生命从同一时刻生效。
- 每场最多同时存在一种大面积视线／路线改变机制：雾、墙、毒区三者互斥。报警、孵化二选一。缚足不搭牵引、闪现、双刃或震波。后续高难版本要另做可应对性验证。

## 5. 伤害、奖励与脱战

- 普通种类生命以现有约 65～110 为起点，重型约 120～180，精英约 220～300；这是类型预算，不是已敲定的逐种表。优先用空间、行为和搭配形成差异，完成独立测试后再定生命、伤害与金币。
- 新技能普通单次伤害建议 8～18，重型可到 20；一个明确前摇内不把弹片全部叠加成秒杀。M12 同一轮散射对同一玩家最多一次伤害，M17 两枚墨刺同一轮也最多一次；M13 两段与 M25 两段分别提示，分别最多一次命中。
- 只通过击杀／委托结算金币，不引入材料或敌人专属代币。普通敌人奖励可先参考现有 18～48 金币范围，精英单独配置；攻击物、护符、幼体再生成或本体恢复不得形成重复奖励。
- 敌人死亡时解除自身维持的绳索、雾幕、符印、盐墙和未触发孢雷；飞行攻击物在来源死亡后消散。M16 已成功登记的增援属于本遭遇，哨兵死亡不会删除它们；报警未成功则取消预留增援。
- 脱战回收遵守地图稿：保存生命、已用能力额度、死亡槽位与奖励收据，取消未命中的攻击和临时效果。重入先给预兆再恢复冷却，不恢复已消耗的报警机会、钟印额度或母巢孵化次数。
- M29 保存共享生命、两身体槽位、亮核索引、批次与唯一奖励收据；M30 每场至多生成两枚钟印，保存每枚的已生成／已毁状态与剩余生命。脱战时撤下剩余钟印，重入恢复其剩余生命与位置，已毁钟印不重生。
- 状态效果来源使用敌人稳定 ID 加代数；跨区域回收、死亡、存档恢复后不保留悬空减速或减伤。恢复顺序先本体、再从属效果和增援记录。

## 6. 实现接入边界

本稿不修改 `EldritchKind`、`EldritchAbility`、`SpeciesCount`、模型或场景。当前十种使用“物种数＋四个幼体”的固定名册，三十种扩展不能只把一个常量改成 30。

后续制作应把“物种定义”“场景编队与稳定槽位”“运行时成人／幼体预算”分开：物种变多不等于同屏实体变多。攻击可用组合与配置组织，但只有需要时才增加具体行为组件，不为二十种各造一套继承层级。

需要单独支持的功能如下：

| 能力组 | 所需支持 | 首批使用者 |
| --- | --- | --- |
| 实体弹道与拦截 | 确定性飞行、实体碰撞、射击命中攻击物、对象预算 | M11、M12、M17、M23 |
| 多段与时序攻击 | 每段锁定、前摇／恢复、独立命中收据 | M13、M24、M25、M27 |
| 状态与来源链 | 有限减速／减伤、绳结和符印的可破坏对象、死亡清理 | M14、M18 |
| 感知与导航 | 预设掩体节点、模拟声音事件、临时视觉遮挡 | M15、M17、M26 |
| 编队状态 | 一次性报警、可取消预留增援、休眠与特殊入场 | M16、M20、M22 |
| 有限场地对象 | 地雷、可破坏墙、双身体、钟印 | M19、M28、M29、M30 |

所有规则和权威状态留在纯 C# 模拟；Unity 读取确认态画预兆、动画和雾幕，不通过表现改变目标或伤害。新增目录、配置、对象状态和状态编码须进入内容摘要及版本校验；新旧构建与存档不得静默混用。

## 7. 制作优先级与验证

**第一批**：M11、M17。先证明实体弹道、掩体换位和地图遮挡成立，用 A、D 两个白盒就能验收。

**第二批**：M12、M13、M21、M22、M25、M27。补充攻击节奏和水边入场；主要复用已验证的通行与伤害查询。

**第三批**：M14、M15、M16、M18、M19、M20、M23、M24、M26、M28。涉及状态链、感知、临时对象或编队恢复，逐一通过后再组合。

**第四批**：M29、M30。保留为独立可选精英房间候选，房间设计与白盒另行安排；不替代 G 的大章鱼、不阻塞主地图终局。

独立验证至少覆盖：

1. 每个新攻击有成功命中与正常躲避／阻挡／打断的正反例；基础手枪与近战能在目标空间完成对应反制。
2. 玩家堵住出生口、四人分散、技能超限、单位死亡和区域回收时，仍满足成人／幼体／效果上限。
3. 缚足不硬锁、盐墙不封死干地、雾不让敌人隔雾精确开火、寄箱不替换保障补给、报警不无限造兵。
4. 多段攻击不重复命中，M29 不重复结算，M30 已毁钟印不在回收或读档后复原。
5. 报警、缚足、符印、墙、双身体和钟印中途保存／恢复后，四客户端状态一致，伤害与金币收据一致。
6. 真人首次试玩能认出“出怪口—预兆—攻击—可用反制”，不靠背图或高阶装备才能处理；每局种类和教学数量符合 8～12 种目标。

当前仅做设计与审阅，不运行游戏全量测试；未验证模型表现、实机手感、长期平衡、多人状态和性能。

设计审阅：独立审阅确认种类职责、战区位置、预算和恢复规则可用于制定计划；提出的寄箱休眠体与 8m 出生距离冲突已按预放单位例外、提前占槽和揭露预警补齐。
