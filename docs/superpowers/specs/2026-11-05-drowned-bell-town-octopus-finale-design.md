# 沉钟镇关底：深渊凝视者与沉钟祭港

日期：2026-11-05。状态：关底与战斗区域设计；未修改游戏代码、Unity 场景或资产。本文替代地图稿原 G 区的两批普通敌人终局。

## 1. 关底定位与沿用的设定

关底固定为已有的克苏鲁大章鱼 **「深渊凝视者」**。沿用已确认的乌贼式后倾长囊、三眼、礁壳与八条触手，不另做人形克苏鲁。外观与历史确认见 [原设计](2026-11-03-cthulhu-octopus-boss-design.md) 和 [模型视图](../../concepts/abyssal-watcher/README.md)。本轮重点是将已有 BOSS 作为沉钟镇唯一主线终局，安排它与镇区、武器、地形破坏和结算的关系。

保留用户已经确认的规则：

- 本体固定在中央海域，朝南，头部小幅偏转；战斗期间头部始终出水，死亡才沉海。
- 前四条 A01～A04 攻击，后四条 S01～S04 支撑；八条均有独立血量、可断且本场不再生。
- 本体与触手生命完全独立。打触手降低威胁，不把触手伤害转移给本体；本体归零即可胜利。
- 中央主眼增伤、不能独立摧毁；身体始终能受伤，没有必须先断肢的无敌阶段。
- 最多同时 1～2 条攻击触手发招；下砸破坏径向长条平台，横扫不毁板。正面喷墨留下短时伤害与减速区。
- 不增加抓取、卷起、举起、抛掷、后腕攻击、再生或全周转身。四条攻击触手全断后只剩正面喷墨，这个战术结果保留。

体验目标：玩家从「贴近输出／退后避险」逐渐转向「先断哪条腕／是否修桥／怎样接应落水队友」。终局目标 **4～6 分钟**，整轮仍以 20～30 分钟为目标；具体数值必须由白盒实测确定。

## 2. 镇内位置与进入顺序

沿用地图西北角 `(0,0)`、向东和向南递增的米制图稿坐标。G 调整为 **沉钟祭港，中心 `(72,76)`**；主体环道外径 44m，包络约 `(50,54)`～`(94,98)`，中央是海水，不是实心广场。地图总包络仍为 160×128m。

12 号沉钟礼拜堂移至 **`(86,47)`**，内部仍为单层 10×12m，用作读解法、观察 BOSS 与战前集合；启动祭火设在南侧入口桥末端 **`(82,59)`**。礼拜堂不是战斗时可购物、隔墙输出的避难商店。

| 连接 | 设计落点与用途 |
| --- | --- |

| 回程 R | 击败 BOSS 后，祭港西南 `(57,91)` 的检修桥免费展开 → `(54,101)` → 归航码头 `(25,111)` |
| 可见性 | 从档案馆后段可见头冠轮廓和钟塔；真正技能提示在近场清晰显示。房屋、石墙阻断外围跨街狙击，不以雾或低栏杆假作实体遮挡 |

C 供能、E 开闸、F 读档三个免费状态齐备后，祭火才可启动。玩家可提前观察场地。发起者交互后，所有在线活动成员须位于祭港战斗范围并确认就位；倒地成员先按既有救援／复活规则处理，离线或等待玩家不计。开战不收费、不消耗任务道具。人数在本次尝试开始时锁定为 1～4；中途断线不缩血，新到玩家等待本次尝试结束后参加。

## 3. 场地：内圈攻击，外圈换位

下表半径均相对 BOSS 中心。角度按图稿东为 0°、南为 90°、西为 180°、北为 270°。

| 空间 | 白盒初值 | 玩家选择与限制 |
| --- | --- | --- |
| 中央深水 | 半径 12m 内除前侧石带／射击台外为水，本体头宽约 8m、高约 10m；触手自然展开约 26m | 不要求游近本体，也不把水面当站立地面。触手最大伸展需覆盖至 22m 外沿 |
| 内圈木石战斗带 | 半径 12～20m，径向宽 8m | 主要输出与躲触手的空间。大部分为固定地面，前半圈四条指定木板带可毁 |
| 外圈石质绕行路 | 半径 20～22m，净宽 2m，连续、不可毁 | 低效率绕行与紧急撤退。它能避开内圈横扫和喷墨，但径向下砸的伤害预警可延伸至外沿；不是站着无伤输出的位置 |
| 三个近身射击台 | 南半圈 50°、90°、130°；4m 宽，从半径 12m 向内伸至 9m，固定石台 | 手枪可从这里攻击头部或主眼；以实际三维命中距离校核常用站位至有效主眼表面 ≤10m，留出 12m 手枪射程余量。石台不毁，下砸／墨区可命中，半径12m外的台根也受横扫威胁 |
| 射击台侧向连接带 | 南半圈 35°～145°、半径9～12m 的连续3m宽石带，连接 P1～P3 | 台尖可沿石带侧移，不是三条死胡同。横扫内界为12m，台尖内侧也可避扫；下砸和喷墨仍可针对石带，不能原地无伤站桩 |
| 四处整队石台 | 对角方向，中心约 `(58,62)`、`(86,62)`、`(58,90)`、`(86,90)`，各约 4×4m，接外圈 | 供救援、转向和观察，保留至少一侧出口。少量实心矮石挡普通平射，不挡大触手；不提供对墨区的神奇免疫 |
| 上岸低台 | 内外缘约每 8m 一个有效低台，前部射击台另设内侧低台；外侧低台延至半径 25m 的浅台 | 以 5m 击退后的实际落点测试，最近可上岸路线目标 ≤6m。确定性地形必须有真实坡口／登岸边，不只摆梯子美术。图上突出四处主要口，不表示只有四个 |

G 使用圆形净空，不按 44×44m 实心矩形占地。F 中心微移至 `(105,98)`，左上角约 `(93,89)`，距 G 中心约 24.7m；相邻段留水道，石台和栏杆不得伸进 F 的可走区域。正式白盒需核对至少 2m 的局部结构间隔；必要时只微移 F 西缘或石台，不挤压 4m 横移通道。

BOSS 面向南侧三处射击台。后半圈适合绕行、复苏和击打后侧身体／支撑腕，正面主眼由本体遮挡；不能从背后穿透头部命中主眼。后方威胁较低是保留的设定，代价是没有 1.5 倍主眼收益与更长换位距离，不另加背刺惩罚。

## 4. BOSS 在哪里出现，攻击怎样进入场地

G 不再使用 G1～G3 普通怪出生口。BOSS 只在中央 `(72,76)` 从海中升起一次，先有海泡、钟声、八腕轮廓，再给约 4 秒无伤登场。前四腕对应南半圈四个进攻方向；后四腕保持北半圈支撑。它们是同一 BOSS 的八个稳定部件，不是八个普通怪人口槽。

首版 **不召唤杂兵**，不并置牵引、闪现、孵化或普通精英。启动前要求 A～F 活动战斗已结束或按普通规则暂停，BOSS 战中暂停普通遭遇生成。玩家离开祭港可以撤退，不能一边在街外安全射击一边维持本体伤害：BOSS 伤害请求要求射手位于祭港战斗区（主体环道、射击台、整队台及其低台）；入口桥外不具备攻击资格。边界通过岸灯与进入提示明确，不做不可见墙或突然关门。

| 招式 | 可读信息与覆盖 | 对应选择 |
| --- | --- | --- |
| 径向下砸 | 触手举高，锁定一条约 2m 宽的径向带，前摇先用现有约 1.5 秒；到落点前不追踪拐弯。伤害长条可跨内外圈 | 横移离开长条后继续输出；若担心毁板，提前退到石路并横移。不可站在外圈原轴线上硬等 |
| 内圈横扫 | 明显后摆，约 1.2 秒前摇；覆盖前方局部扇区的半径12～19.5m，内侧连接带9～12m与外圈20～22m不在横扫伤害带 | 近内侧者退入石带，外侧者退向外圈，也可绕出扇区；不要求跳跃／蹲下。后摇期间近战可击打仍贴近平台的腕段 |
| 正面喷墨 | 口器蓄力改为约 2 秒（旧配置约1.2秒，须调整），瞄准一次正面不超过45°的局部扇区；落地墨区约 6 秒，减速并持续伤害 | 从相邻射击台或外圈绕开，不把正面三个台同时涂满；墨区不覆盖上岸口与外圈整圈 |
| 断肢反馈 | 单腕生命归零即取消该腕尚未结算的攻击，断落入水；本体不扣额外血 | 先拆威胁腕换取稳定站位，或者抓主眼窗口更快结束。断腕不产金币／弹药，防止反复开局刷资源 |

第一版不加独立震荡环、眼部激光或抓人机制。伤害可先参考已有下砸 36、横扫 24、墨区每秒 8，击退 3m／5m；这是现有参数参考，不是已适合新场地的平衡结论。预警覆盖必须与权威几何完全对应，墨特效不能遮住第二条触手的前摇。

所有单招及叠加攻击都进行可达安全点校验，包含射击台最内侧、台间石带和墨区减速站位，不仅检查狂暴。喷墨2秒内至少能沿连接带离开已锁扇区；若不满足便减小扇区或延长该次前摇，禁止必吃攻击。

狂暴的双腕前摇可以重叠，但落点至少错开 0.6 秒；调度拒绝会在下一次伤害时刻封住所有合法退路的组合。从每个被锁定站位，以 3m/s 普通陆速（处在墨区则计实际减速）和角色半径检查至少一条可到达的无伤路线；不满足就推迟第二次攻击。这个组合检查是新场地的接入要求，不能假设旧系统已具备。

## 5. 战斗推进与地形破坏

| 节奏 | 规则与目标 |
| --- | --- |
| 登场 | 约 4 秒，无伤；八腕与全血条出现，玩家认清朝向和外圈 |
| 常态：本体 100%～40% | 同时最多一条攻击腕。下砸／横扫与间歇喷墨让玩家学会横移、退外圈和换射击台；不按固定时间强制转阶段 |
| 狂暴：本体 ≤40% | 现有约 3 秒狂暴提示先中止旧攻击，之后最多双腕。保持已断肢和已经毁坏的木板，不回血、不再生。通过错峰和组合检查增加压力，保留完整前摇 |
| 本体归零 | 立即停止新攻击并清除待命中的伤害，墨区不继续杀人；约 6 秒熄眼下沉。随后胜利、金币结算与回程桥在一次权威提交中落定 |

只设两个战斗阶段；「先观察、选断腕、最后压主眼」是玩家战术节奏，不伪造额外的 70% 无敌转阶段。后四支撑腕被打断只移除对应部件，不秘密转为攻击腕。若四条攻击腕全断，BOSS 继续可受伤并仅用正面喷墨。

前半圈四条指定可毁板带 W1～W4 设在约 30°、70°、110°、150°，各宽 2m、从半径 12m 至 20m，最多四个连续 2×2m 板段。触手下砸仍能打断内侧环路；**外缘 2m 石路、三个近身石台及其连接带、入口和上岸低台不毁**。整圈不存在唯一一块被毁后只能付费才能继续的地板。断口用桩头和破木边缘清楚显示，不让碎板继续提供隐藏站立面。

每条板带外缘有固定维修绞盘；修复一条已毁带白盒初值 40 金币，可按损毁批次重复维修，但永远可不修。危险预警占用绞盘时不能打开交互。金币验证、扣费与恢复指定板段同帧结算，按请求 ID 与尝试 ID 去重；没有木材、鱼骨、材料掉落或旧板材退款。已完整或请求失败不扣金币。

## 6. 单人、合作、补给与重试

- 单人不要求同步拉杆、分头站点或队友解控。全程基础手枪能打到本体，基础近战能打到停顿腕段；不要求狙击枪、泳圈或特定手雷。
- 四人可以一人引腕、一人拆腕、其余打主眼，也可以自由换位。目标锁定按权威状态稳定选择，不强制职业职责。倒地救援仍按原规则，不因救人自动获得无敌。
- HP 可先沿用当前 BossConfig：本体 2400、攻击腕 300、支撑腕 220；每增加一位参战者，本体 +65%、触手 +45%。单次开战冻结人数，断线不重算。这些都是待测起点；若 4～6 分钟不达标优先校准有效输出窗口和弹药预算，再调血量。
- 礼拜堂给出开战前弹药检查。每次成功开战时，免费发放一次**仅本次尝试使用的基础手枪弹药池**，不占背包，不可交易／出售／丢弃，基础手枪装填优先使用。初值按 `向上取14的倍数[1.5×(本体HP＋四条攻击腕HP)/(参战人数×基础手枪单发伤害)]` 计算：当前35伤害下单人168发，二人126发／人，三四人112发／人；含约三分之一空枪余量，不计主眼加成。它是有限的尝试补给，不在战中循环补充；自购高阶枪弹、治疗、手雷仍由金币承担。
- 尝试弹池与装入弹匣的来源都由权威状态保存；金币弹药库存不被覆盖。离开祭港或本次尝试结束时回收该玩家未使用的专用弹（含装匣），不能带去街区打怪；离场再进不重发。全队失败后的新尝试重新领取，新旧尝试ID隔离、同一请求不重复领取。需要新接入，不能声称现有弹药已经支持。即使单人金币为零并在上一场耗尽所有弹药，新尝试也有完整有限火力；仍打空则可退回重试，避免只能等7发而BOSS每次回满血的硬锁。
- 战斗始终可沿原入口撤出。所有未倒地参战者离开战斗范围或全部失去可战斗状态后，给 **10 秒**救援／回归窗口；仍无人可战斗则结束本次尝试，BOSS 生命、八腕和四条木带免费复位、清除危险区。不继承普通区「12 秒回收且保留残血」规则。消费过的弹药、治疗和维修金币不退还。
- C／E／F 状态、已清街区、捷径与个人登记点保留；重试不再清镇、不收入场费。重连／读档恢复当前尝试、锁定人数、断肢、木板、时钟与结算状态，不把一次重连当作新尝试。
- 沿用现有 BOSS 的贡献奖励资格：本次对本体或任一腕造成过伤害的玩家获得一次配置金币奖励（现有参考 600／人）；救援与胜利属于队伍共享结果，不要求每人最后一击。断肢没有单独奖励。离线参与者的已产生奖励写入其本局记录，重连不重发。
- BOSS 完成死亡状态后设置 `TownFinaleCompleted`、开启 R、提交奖励收据；重复死亡包、存档恢复或再次进入都不重复发奖。码头按地图稿的全员确认规则结束本轮，不自动把未准备好的队伍传走。

## 7. 接入边界与白盒顺序

本次读取了当前 `BossConfig`、`BossState`、`BossSystem`、`BossArena`、`HookGame.Boss` 和 `BossSettings.asset`。已有模型、动作引用、独立腕血、40% 狂暴、倒地后无目标重置与贡献发金币逻辑；它们仍是既有平台模式 BOSS，**不能据此宣称沉钟镇终局已接入**。

实施时保持纯 C# 模拟权威，需完成这些连接：

1. 将旧固定世界坐标、初始 3×3 平台和旧环形生成规则，改为读取本地图的中心、朝向、祭火与战斗范围数据；八腕编号稳定。新图的静态可走面、障碍和低台不能由 Unity 物理独立推断。
2. 将 G 从普通遭遇表移除，接 C/E/F、队伍就位、普通怪暂停和唯一 BOSS 尝试状态。旧「可选挑战」与本图 G 使用同一套 BossSystem 能力、不同地图配置，帧同步核心不加玩法分支。
