# 海岛异教生物：十种可战斗敌人

用户目标：设计并实现十种克苏鲁风格敌人，具有实际玩法差异，可参考流行同类游戏。实现选择：沿用现有卡通海岛、纯 C# 确定性模拟、确认态 Unity 表现；以岛上探索和枪械战斗为主，9 种在陆地入场、1 种威胁岸边水域，原创轮廓与名称。保留原有敌人。

| 名称 / 标识 | 外形与栖地 | 战斗职责和反制 |
| --- | --- | --- |
| 潮痕眷属 / DeepOne | 弓背鱼人，陆地 | 追击短距离爪击；后退诱空再反击 |
| 逆棘奔兽 / ReefRam | 四足棘兽，陆地 | 蓄力后沿锁定方向冲锋；侧移躲避、追打硬直 |
| 圣螺守卫 / ShellWarden | 螺壳重盾，陆地 | 正面减伤，近身重砸；绕背或趁恢复输出 |
| 裂瞳观测者 / RiftEye | 悬浮独眼 | 直线凝视光束；离开预警线、命中打断蓄力 |
| 溺钟引路者 / DrownedBell | 倒悬灯笼水母，水面 | 范围牵引；离开警戒圈防止被拖入海 |
| 腐潮囊 / BlightSac | 膨胀孢囊，陆地 | 锁定地面生成持续毒区；看到圆圈立即移位，击杀清除毒区 |
| 无面唱诗者 / ChoirPriest | 带鳃长袍，悬浮 | 治疗附近受伤同伴；优先击杀或打断祷告 |
| 千嗣母巢 / BroodMother | 多眼触手卵巢，陆地 | 有上限地召出幼年眷属；尽早击杀母体，范围清理幼体 |
| 折影行者 / RiftStalker | 不对称细长触肢，悬浮 | 标记落点后闪现伏击；离开落点，利用恢复窗口 |
| 星骸执钟者 / StarHerald | 五角星冠与环形躯体，悬浮 | 环形震波，内圈安全；进内圈或退出外圈 |

每种敌人均有生命、移动、目标、前摇、效果、恢复、死亡、刷新和金币结算。固定名册 10 个母体槽及 4 个幼体槽；初次等待 30 秒，种类初次解锁错峰 10 秒；最多 4 个母体同时出现，母体死亡结算后 90 秒刷新，召唤物每代母体最多 4 个。稳定槽位、轮转生成避免种类饥饿；出现后有 1.5 秒不发动攻击的入场预兆，期间仍可被玩家命中。数字为本轮设计选择，可在配置调整。

攻击落点/方向在前摇开始时固定；所有距离毫米、时间 30 Hz tick。地面敌人复用平台导航；水面敌人检查海面占位；悬浮敌人从可达陆地入场，移动时可越过岸线但不穿实体障碍。枪、锅、手雷、钩索都接入；枪和锅造成伤害，钩索可打断施法。护甲方向使用攻击来源，爆炸绕过正面护甲。显式序列及命中掩码防止冲锋多帧重复命中。

金币归致死玩家，死亡和待结算收据进入存档；溢出时保留待结算、禁止刷新，不产生部分信用。新配置、状态及固定图鉴数据进入握手/兼容性标识。旧版存档按已有兼容校验明确拒绝，不做隐式格式迁移。

Unity 使用独立模型构建与动画表现，十种不同几何轮廓、颜色、眼/触肢、生命条、攻击线/范围圈；表现不写模拟状态。正式 FishingSettings 开启新敌人，提供编辑器图鉴预览与截图验证；自动战斗测试仅在 tools/，不挂正式场景。

验证：十种能力正反例、击杀/打断/召唤上限、导航与障碍、配置和状态拒绝、持久化后重放、真实四客户端一致性、既有战斗回归、Unity 编译和可视化检查。全量验证依改动实际范围执行；实机手感和长期平衡不冒充已验收。
