# 灰隼航空基地：紧凑三据点沙盒地图

日期：2026-11-19。版本：**V4，三种防守方式与明确站位、射向、退路**。状态：设计提案，尚未搭建 Unity 白盒或试玩。几何唯一来源为[布局数据](../../concepts/grayfalcon-small-sandbox.layout.json)，当前版本 `distinct-strongpoints-v4-2026-11-19`；下文坐标与尺寸均为候选值。

## 需求与修订目标

保留用户已经确认的废弃军事航空基地主题、第一人称射击、小型自由沙盒、军事训练操场，以及机库和军需仓两处可进入建筑。三个战略据点应比较易守难攻，支持坚守一段时间、观察失守风险、转移到另一据点重新组织防线。

针对“很多区域没用”的反馈，V3 将地图包络由 **100×80 米缩至 84×62 米**。包络面积从 8,000 平方米减至 5,208 平方米，减少 **34.9%**；这不是实测可走净面积，也不代表移动时间等比例缩短。

本版保留 84×62 米包络与外围关系：**A—C 的短路穿过操场，B—C 的两条路分走战机两侧。** 训练带并入操场北沿，独立指挥楼已从可玩图删除，通信地标可合并到军需仓屋面。道路压缩为组团之间的连接口。

本次针对“战略要点不清楚、三个点缺少区别”的反馈，确定三种空间行为：**A 两翼夹射入口，B 先守前线再退后线，C 借高货架守近距离折角。** 图面需要分别展示站位、主要射向、后口观察和撤退预案。差异来自固定体块、可见方向和后撤空间，不依赖武器加成、强制守卫计时或新交互机制。

所有据点数量、坐标和空间细节仍为设计判断。四人合作沿用既有方向，后续同时验证单人和四人。地图不依赖固定波次、固定守卫时长、自动失守计时、强制跑腿或新增必需的有限弹药；探索奖励与完整游戏模式另行配置。

## 区域为何值得进入

每处可玩空间至少承担战斗接近、据点转移或可选探索之一。功能成立应由实际走位和交战证明，不能只给空地起一个名字，也不要求用道具塞满每平方米。

| 区域 | 玩家为何进入 | 空间安排 | 实际取舍 |
| --- | --- | --- | --- |
| A 营房夹院 | 两侧射手夹射同一入口，互相接替换弹 | 南北营房、两翼挡块、东主口与西后口，约 19×11 米院地 | 射界集中在东口接近段；后撤必须留意西巷与西门接近路 |
| B 机库 | 用两道防线争取整理队形和撤退的空间 | 北主口、东后口；前后两组维修设备留中央射界与西侧换线通路 | 退到第二线会失去门口控制；东门受压时不能继续留守 |
| C 军需仓 | 借高货架切断西门直线，守内弯并接应队友 | 西主口、南后口；高货架北端接墙，敌人绕南端进入射界 | 近距离易集中火力，但预警和反应距离短，无法直接观察操场 |
| 操场 | A—C 快速转移、观察接近者、掩护队友横穿 | 24×18 米主场，A—C 短路穿过场内 | 路短、视线开阔，横穿时也更暴露；不能把它当第四个强据点 |
| 北沿训练带 | 在操场短路受压时选择较长的绕路 | 训练设施并在主场北沿，绕行走北侧，局部打断视线 | 比横穿更长，只减少部分方向的暴露；设施是否挡住真实眼高需验证 |
| 战机与机坪 | B—C 之间根据敌人方向换路，借机身阻断追击视线 | 战机横置在两条路线之间，北路靠中央连接，南路靠外围接近面 | 北路较短、受道路影响更大；南路较长、直接面对南入口 |
| 营房西巷 | 从 A 后口向 B 转移，顺路检查可选遗留箱 | 营房提供连续体块遮挡，西巷在南端接横向连接路 | 退出后仍需跨越西门来敌方向；不能作为保证安全的通道 |
| 东检查口与组团道路 | 观察东侧来敌、进入操场或仓库接近面、完成短距离换侧 | 岗亭与军车放在路侧；道路在操场与仓库之间转折 | 路口被占会改变多条路线，玩家需要提前判断，而不是在这里无目的停留 |

围界外的接近带可以只供敌人入场和玩家观察，不必全部开放给玩家。边角如果没有支撑任何行动，应在白盒中收拢可见边界或归入布景；不通过增加强制拾取物把它变成必经地。

## 三个战略据点：站位、射向和撤退

图中编号表示建议职责或先后阶段，不是固定队伍人数。四人时可安排机动补位；单人需要根据威胁切换位置，不能同时获得所有观察方向。A、B 的 `positions.point` 分别为 `(20,15.5)`、`(25,44)`，是外部路线的衔接点；具体射手站位以下表与 `tactics` 为准。C 衔接点与主射位均为 `(73,33)`。

| 据点 | 具体站位与防守方向 | 空间优势与代价 | 何时撤、向哪里撤 |
| --- | --- | --- | --- |
| **A 两翼夹射** | ① 北翼 `(21,12.5)`、② 南翼 `(21,18.5)`，共同瞄向东口外 `(34,14)`；③ `(13,16.5)` 观察西后口 | 营房保护南北，两翼射界在玩家前方汇合；可接替换弹。只能控制入口接近段，不能宣称控制整片操场 | 东口内开始积压或一翼被迫离位时，射手先向西后退，再在 `(14,16.5)` 汇合，经西口、西巷去 B |
| **B 两线后撤** | 阶段① `(27,40.5)` 向北门外 `(28,33)` 射击；阶段② `(28,48)` 向室内前沿 `(28,41.5)` 射击；③ `(32.5,44.5)` 观察东侧门 | 前后两组设备形成纵深，退线后仍有整理空间；失去前线会缩短反应距离。①②不能被理解为两排玩家同时朝前开火 | 北门守不住先沿西侧换线到②；前线设备被越过或东门将受压时，由东侧门退出，经机身北侧去 C |
| **C 折角近战** | ① `(73,33)` 向西侧内弯 `(65.5,33)` 射击；② `(70.5,34.8)` 观察南门；③ `(73,26.5)` 在货架内侧接应 | 高货架遮断西门直线，来敌须绕弯进入近距离射界；换来集中火力，也失去远距离观察与反应时间 | 货架末端挡不住或南门出现接近者时，提前从 `(70.5,33)→(70.5,39)` 出南门，绕机身北侧去 B |

### A：两翼互相接替，不横穿同伴火线

两块实体挡块分别位于院内北、南侧，射手站在它们的内侧开口附近。两条主要射线穿东口后汇合，交汇点在玩家前方，不穿过另一名射手。后撤时，①经 `(17,12.5)`、②经 `(17,18.5)` 向西移，再汇合到 `(14,16.5)`；这样不从对侧射手身前横穿。③先观察西口与西巷，为队伍报告退路情况。

### B：先离开前线射界，再由第二线接替

阶段①受压后，示例换线为 `(27,40.5)→(20,40.5)→(20,48)→(28,48)`，从西侧绕开中央射界。阶段②的射击只有在前线队员离开该射界后才成立；图面应明确标出“①→②”，不把前后位置画成同时射击的固定编队。

第二线退出示例为 `(28,48)→(28,50)→(33.5,50)→(33.5,44.5)→(37,44.5)`。东侧门需要提前观察；若出口已被占，图示路线不再可直接执行，不能依赖自动开门、无敌撤退或敌人无法寻路来保证脱离。

### C：让敌人绕货架，再守内弯

高货架从北墙延伸到 `y=31`，完全遮住西门到内侧接应区的直线。西门入场路径改为 `(65,29)→(65,33)→(73,33)`；主射手的箭头停在仓内转角，不穿货架或西墙指向操场。③接应位置的换位线经过 `(74,29)→(74,34.8)`，从主射手身后靠近南门区域。主射手离开时停止该方向射击，避免队友经过撤离线时仍向同一条线开火。

货架末端与南墙之间保留实体通路，正式敌人必须能绕过，不能由导航漏洞形成永久安全位。该据点依靠近距离转角，反应时间比 A 更短；南门观察不能被货架内侧的视觉保护取代。

## 转移路线与暴露取舍

```text
            北沿训练绕路
      ┌───────────────────┐
      A ── 横穿操场短路 ── C
      │                    │
 前口近路／西巷后路        │
      │       机身北路     │
      B ════════ 战机 ═════┤
               机身南路 ──┘
```

连线表示空间选择，不是强制顺序。实际折线和碰撞以布局数据为准。

- **A—B**：前口近路经过 A 主防口和南营房东侧；西巷后路从 A 西后口出来，经营房西侧后跨西门接近路，再由 B 北口进入。前者较短，后者可借营房遮挡但跨路风险更高。
- **A—C**：短路由 A 东口出发，经 `(44,20)` 真正横穿操场，再从 C 西口进入。北绕路经过 `(31,6)→(58,5.5)→(60,19)`，利用北沿训练设施遮挡部分视线后接 C 西口。两路进仓后都经 `(65,29)→(65,33)→(73,33)` 绕过高货架，不再使用旧版的 `y=29` 直穿路线。两路共用 A 东口与 C 西口。
- **B—C 北路**：由 B 东后口经 `(41,44.5)→(41,38.5)→(61,38.5)→(61,44.5)`，绕过 C 后口挡墙，再从 `(70.5,39)→(70.5,33)→(73,33)` 进入仓内。机身阻断部分南侧视线，北侧道路和接近口仍会影响此路。
- **B—C 南路**：由 B 东后口经 `(40,44.5)→(40,58)→(63,58)→(70.5,44.5)`，再通过同一南门与仓内连接。飞机遮挡部分北侧视线，但路径较长且暴露于南入口。

B—C 两路共用建筑后口，某个后口被占时，两条分支都可能受影响。图纸不把两根线当作两个永远独立的出口。目的地也可能已有敌人；队伍需要观察、侦察或安排接应，不能默认到达下一个点就自动获得安全。

失守应由可感知局势产生：入口压力超过当前火力组织能力、侧口出现追兵、前沿不断后退，或伤员使队伍难以继续守卫。记录玩家何时决定转移及理由，不规定某据点守够多少秒就必须崩溃，也不在据点内部突然出怪来抵消有效防守。

## 可选探索与外围接近

仅提出两个可选探索容器摆位：西巷遗留箱 `(8,28.5)`，以及战机南路附近的检修车 `(42,55.5)`。它们让玩家有机会检查已有支路或换路时停留，物品内容、奖励和刷新另配；不新增必需弹药，不设置必须往返取物的任务，也不以容器存在证明整条路线已经有用。

W 西后勤门沿 `y=32` 进入，影响 A—B 跨路段与 B 北门；E 东检查口沿 `y=19` 进入，经操场和仓库之间的连接影响 A—C 线路；S 南机坪缺口从战机东南侧接近，影响 B—C 南路及后口外侧空间。三者是接近方向，不是固定刷怪坐标或同时启用的波次规则。

围界仅在图纸标注入口开放。外围出生需要合法位置和通向战场的真实路线；玩家已看清的夹院、机库、仓库或脚边不能无预警生成敌人。未确认的敌人数、持续压力和调度方式属于后续玩法配置。

## 白盒验证与交付边界

先用一处完整据点验证守口和退出，再连接另一据点测试转移，最后完成三个点与两处路线选择空间。地图是否紧凑、各区域是否有价值，均以实际行动判断。

| 检查问题 | 观察依据 | 优先调整 |
| --- | --- | --- |
| 操场是否被实际使用 | A—C 转移中，玩家是否选择横穿，以及能否说出不用北绕路的理由 | 两路长度、暴露和入口位置 |
| 北训练带是否有价值 | 短路受压时，是否出现有理由的北绕选择；真实眼高能否获得局部遮挡 | 设施位置、遮挡高度和绕行距离 |
| 战机两侧是否形成选择 | 分别从道路和南入口施压，观察 B—C 路线选择是否改变 | 机身位置、两路暴露与转角 |
| A 是否形成真正夹射 | 从两侧真实眼高看东口，检查挡块遮挡、交叉点和换弹接替 | 站位、挡块内缘和入口宽度 |
| B 是否能逐段后撤 | 第一线受压时记录是否能离开中央射界，第二线何时接替 | 西侧换线路、两线间距、东侧退出空间 |
| C 的折角是否有意义 | 记录绕货架的敌人是否可见、可追击，以及主射手的反应时间 | 货架长度、末端通路与南门观察位 |
| 据点能否守后再撤 | 记录稳定守卫、侧口受压、撤离决策及进入下一点后的队形 | 开口、前沿纵深、后口缓冲和接应位置 |
| 四人是否能通过 | 换弹、倒地和一口受压时检查侧门、转角和道路连接 | 真实碰撞净宽、家具和挡墙 |
| 是否仍有无用途空地 | 记录战斗接近、转移、侦察与可选探索的实际路径，区分必要视距和纯冗余 | 收拢边界或删除重复空间，避免强加收集任务 |
| 是否出现永久安全位 | 正常敌人使用全部合法开口追击，检查门后与战机周边 | 导航、侧口可达性和可感知压力 |

本轮只修订地图方案，未进入 Unity、制作三维资产或修改游戏代码。全部尺寸、碰撞净宽、射界、可守程度和路线偏好都需要白盒试玩。后续接入正式地图碰撞、AI 或交互时，再按项目要求验证确定性和多人一致性；本轮不运行 `./scripts/verify.sh`。
