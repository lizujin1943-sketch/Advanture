# 鱼挣脱与落水表现

## 玩家体验

普通鱼和食人鱼在回拉耐力耗尽后，保留原来的鱼种、重量、品质及模型，从当前位置开始挣扎、抛落和下潜，不再直接消失。主动取消、角色失去出钩能力或断开时，已挂住的鱼也使用同一释放过程；只有耐力耗尽增加 `Escapes` 并触发原有的“鱼挣脱了”提示。

| 阶段 | 时间 | 表现 |
| --- | --- | --- |
| 挣扎 | 0.3 秒 | 在脱钩位置扭身、甩尾 |
| 抛落 | 0.7 秒 | 沿弧线飞向海面，鱼头跟随轨迹倾转 |
| 入水、下潜 | 0.4 秒 | 扩散水环、低多边形水滴，鱼体下沉到水下 0.7 米 |

释放时优先朝远离玩家的方向寻找落点，并避开当前地块、陆地和岸边障碍。普通鱼完全下潜后才生成下一代并进入刷新等待；食人鱼完全下潜后进入其配置的刷新等待。挣脱期间不可再次钩住，也不产生伤害、金币、鱼骨或捕获数。空钩按原流程收回。

## 职责与联机

- `CatchEscapeMotion`：纯 C#、整数毫米和固定帧数的轨迹采样、海面落点选择。`CatchEscapeState` 保存起点、落点和当前帧，不依赖 Unity 时间或物理。
- `HookGame` 与 `EnemySystem`：释放所有权、推进对应鱼类的挣脱状态、完成下潜后转入刷新。耗尽与着岸同帧仍优先按挣脱处理。
- `CatchEscapeStateCodec`：将普通鱼和食人鱼的挣脱字段加入完整 checkpoint，并校验阶段、计时、坐标和所有权。恢复任一中间帧可以继续同一轨迹。
- `CatchEscapePresentation`：只读确认帧，计算鱼身姿态、尾部摆动和水花；不修改模拟状态。水花对象按鱼复用，结束、离房和重开时隐藏，销毁时释放自建材质与网格。
- `FishingPresentation`、`EnemyPresentation`：接入共享表现。食人鱼瞄准辅助排除挣脱中的目标。

规则与状态格式升到 **v14**，输入格式仍为 **v7**，房间协议仍为 **v14**。不同规则版本的客户端不能混连；旧 v13 checkpoint 不进行隐式迁移。各端沿用原有帧同步传输，无新增动画 RPC 或本机随机播放计时。
