# 沙漠之鹰实施与验证

2026-11-02，正式工程 `samples/TacticalGame.Unity`，平台场景 `Assets/HookIsland/Scenes/HookPlatform.unity`。对应[设计](superpowers/specs/2026-11-02-desert-eagle-design.md)，当前采用无限备用弹药、定时换弹与持枪准星。

## 使用

- 新开局每人一把沙漠之鹰，背包中装满 7 发，绑定第 6 个快捷栏；初始手持钓竿，原 1–5 号绑定保留。重开重新配发，读档／重连只恢复已有物品。
- 备用弹药无限。左键单发，按住不连发；空仓不自动换弹，按 R 等待完整 **1.8 秒**补满。满弹匣不进入换弹；取消换弹保留原弹数，重新换弹需要完整计时。
- 持枪时显示白色十字准星：第三人称在相机视口中央，俯视跟随鼠标；四条短线随移动散布张开、停下后收拢。菜单、商店、背包、建造、其他工具及无法使用枪械时隐藏，换弹期间保留。弹药显示为 **`7 / ∞`**，换弹进度沿用当前快捷格。
- 商店售枪 300 金币、每批 2 把，仍按原商人时钟补货；不再售卖子弹，旧货架的子弹购买请求也明确拒绝。旧档已有散弹原样保留，可整理或转交，当前换弹不消耗它们。
- 35 伤害、12 m、0.6 秒射击间隔。队友伤害 50%，与护甲合并后只向上取整一次：无甲 18 点，100 护甲 9 点。关闭整蛊只关闭轻推，不免枪伤。
- 枪击不领取金币、鱼骨或捕鱼连击；其导致的倒地、击退脱钩等执行现有规则。R 按下时有有效倒地救援对象则优先救援；一次按键不会在两种动作间自行转换。

## 事务、联机与存档

开火原子扣一发；换弹仅在完成帧原子增加弹匣空位，同时累计按弹种记录的 `ReplenishedAmmunition`。换弹开始、取消和满弹匣请求均不记补给。库存仍验证守恒：

`地面／背包散弹 + 所有枪装弹 + 成功发射数 = 枪初始装弹总量 + 旧版购买份数 × 每份数量 + 成功换弹补给数`

补给账本不会占背包或变成可拾取子弹。其与弹匣在快照中一起保存，防止读档把旧枪补满或重复结算。旧版散弹不销毁，不悄悄退款，原支出账本继续成立。

成功切换工具、有效救援、倒地、受击位移等在换弹完成帧优先取消；失败切装和普通非致倒地扣血不取消。主动存档等待全队举枪、收势、换弹等动作结束，纯冷却及稳枪恢复可保存。网络检查点可恢复中途动作，重连不补播旧事件或重新抽取已经结算的散布。

当前兼容清单为**规则 33／输入 13／状态 30**，库存为 **BAG4**。2026-11-03 合并螃蟹、枪械和食物配置，地图与状态标记一起更新；按照最新要求，仅保证本版本新存档的保存与恢复，不迁移旧存档。不同版本客户端和旧档明确拒绝，不修改原始文件。

`IslandSave` 通过正常模拟恢复及席位校验确认结果。固定旧档仅用于验证不兼容格式被拒绝，不属于真实玩家资料。下方 2026-11-02 的验收记录是当时版本的结果；合并后的验证见文末。

## 水面受击反馈（2026-11-03）

原水面命中只有存活 0.24 秒的细线圈，缺少水滴和持续涟漪；弹迹使用角色位置估算枪口。现在 `FishingPresentation` 将可见枪械的实际枪口传给 `FirearmFeedback`，弹迹仍终止于确认事件的 X/Z 落点，不跟随之后移动的准星，也不重新抽取散布。

新增 `FirearmWaterImpactView`：短促柔和水柱、小水冠与 9 颗水滴，随后两层圆形波纹扩散并淡出；水花带独立短促水声音效。通过 `Resources/FirearmWaterImpact.asset` 配置，默认水滴最高约 0.32 m、水冠 0.28 秒、波纹 1.15 秒、第二圈延迟 0.12 秒、波纹平面最大直径 1.35 m。复用现有水粒子着色器及水面高度，不改动鱼类原有出入水效果。共享缓冲最多保留 32 处水面受击，逐帧重建颗粒，不按射击次数长期创建粒子系统。

只有确认射击的空目标末端实际位于海面才播放水花。木板按地块覆盖范围判断，不能使用角色带安全边距的站立范围，避免木板边缘误冒水花。命中敌人、队友、商店或其他实体保留原命中效果。去重仍由 `FishingFeedback` 的确认事件消费入口负责；重开／恢复清空全部瞬时水花。没有修改权威命中、伤害、库存、协议和存档。
