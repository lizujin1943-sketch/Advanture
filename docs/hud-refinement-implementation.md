# HUD 精简与收获反馈

2026-10-27，适用正式 `HookPlatform.unity` 场景。本轮只调整 Unity 表现和本地界面交互。

## 最终显示

- 右上钱包仅保留金币图标和金额。移除补给船方位／距离列表、常驻视角文字，以及旧底部生命／耐力面板；商人和视角切换仍可正常使用。
- 任务面板可点箭头或按 J 向左收起，0.22 秒过渡；收起后只留边缘箭头。渲染与指针遮挡使用同一位置，不阻挡已隐藏面板区域中的出钩。
- 获得金币、木材、鱼骨及装备时，头顶与右下角都只显示图标和 `+数量`，无底板、无物品名。右下角仅显示本人最多 5 条，向上滚动并在 4.5 秒内淡出；头顶对各可见玩家最多显示 3 条，1.8 秒内上浮消失。被动提示不吞鼠标输入。
- 耐力弧位于角色左侧，加粗并缩为约 104°。满耐力隐藏，开始消耗时出现；暗底与土黄色填充拉开对比，浅金色残影先保留 0.18 秒，再以每秒 0.9 的比例向当前值收拢。真实进度立即更新，恢复时不保留损失残影。队友只在收鱼或主动游泳时显示未满的耐力弧。
- 头顶和队伍列表血条先用白色标出损失段约 0.1 秒，再由血红色填充在约 0.32 秒内缩短；连续受击会调整目标，不重复延长最初停顿。生命增加、装备上限变化、菜单隐藏及新会话重新建立显示基线。血红色目标保持 `#C4121C`，没有改为粉红色。

## 状态与职责

- `AcquisitionFeedback` 从 `room.State` 确认快照观察金币累计收入、材料余额和装备实例的归属变化；`AcquisitionHud` 只负责图标、数量及滚动表现。没有修改结算、背包或网络状态。
- 首次加入、客户端替换、重新开局、确认帧回退均建立新基线，不重复播放存档收入。重复 OnGUI 只推进动画，不重复产生同一帧的收获。
- 材料拆堆、合堆、整理背包不产生提示；未进入背包的溢出材料不显示为已获得；装备换槽不算新获得，购买／拾取或归属变化才产生提示。
- 材料提示是两次渲染观察之间的实际余额净增加，不是逐事务流水；同一观察间隔内如果同时获得和消耗材料，显示净增加。金币使用累计收入，可以在同一间隔消费后仍显示实际新增收入。
- `ObjectivePanelMotion` 只维护本地收起动画；`HudLayout` 提供渲染和输入共用几何位置。收获提示、旧物资位置和旧底部状态区域不再阻挡出钩。
- `StaminaDrainFeedback` 维护短暂消耗残影；`HealthBarFeedback` 维护按玩家分开的白色受击段与红条缓动。生命、耐力和上限读取确认状态，位置随显示角色；隐藏或长时间停止观察后不回放旧动画。
- 没有新增网络消息、模拟状态或存档字段；正式场景中没有常驻自动游玩、注入资源或截图组件。
