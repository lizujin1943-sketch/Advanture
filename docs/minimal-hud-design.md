# 极简游戏 HUD

2026-10-21。仅重做游戏内 HUD，沿用现有确定性玩法、输入命令、房间与商店规则。

- 左上：队友色标、编号、小生命条；落水、倒地和死亡以图标表示。隐藏队友金币、材料及重复钓竿属性。
- 右上：金币、木材、鱼骨图标与数量；独立菜单按钮。无游戏标题大卡片。
- 底部中央：紧凑生命条及主要耐力条。耐力采用圆角槽、浅色填充、10 等分刻度和半格短刻度，低耐力转琥珀／珊瑚红；数值保留，恢复状态使用图标。
- 右下：背包、建造、帮助图标按钮，保留小按键标记与悬停名称。操作指南收进帮助页。
- 收鱼时角色上方保留小型带刻度耐力条，隐藏“回拉耐力／鱼正在挣扎”等重复文案；挣脱仅短暂显示图标与“挣脱”。
- 建造只在开启时出现材料选择与成本；主 HUD 不再常驻平台尺寸、产出公式、格坐标和教学说明。
- 商店只有靠近且可操作时显示图标与 E；人物头顶仅队友色标／编号与必要状态图标。收益显示金币图标与增量。
- 失败、付费复活、倒地救援等影响决策的提示保留，但缩短文案并使用相同视觉语言。错误不能随装饰提示一起隐藏。

美术选择：深海蓝半透明圆角底，米白图标与数字，薄荷绿耐力，暖金资源，珊瑚红危险。自绘 PNG 图标图集统一线宽，不依赖系统表情字体或新增 UI 包。主 HUD 位置与鼠标阻挡共用布局，空白区域不拦截出钩。

实现约束：布局、绘制资源与游戏视图分工；不修改权威状态。自动化截图和测试仅 Editor／显式开发验收使用，不加入正式场景常驻组件。

## 实现与操作

- `HudLayout` 统一可见区域与鼠标阻挡范围；按窗口尺寸缩放，最低支持 640×360，包含超宽屏布局检查。
- `HudPainter` 管理图标图集、字体样式与圆角／进度条绘制；细刻度至少保留一个实际像素，窄生命条和小玩家标记不会发生圆角边框溢出。
- `GameplayHud` 只读取已确认的角色与房间状态；背包、建造、菜单和帮助按钮调用原有本地意图入口。钓鱼、游泳、耐力恢复、金币和联网规则没有改动。
- 耐力大于 50% 为薄荷绿，大于 20% 且不超过 50% 为暖金，不超过 20% 为珊瑚红；主条保留当前值，悬停可查看精确的当前／上限。收鱼时角色上方的短条使用同一视觉样式。
- F1 或右下问号打开操作指南；Esc 关闭。帮助页沿用菜单输入阻挡，并关闭背包、商店和建造面板；联机房间继续运行。
- 右下背包对应 Tab / I，锤子对应 B。扩建面板关闭后不再阻挡原位置的出钩输入。资源图标、状态图标和按钮都可悬停查看名称。
- 本次范围是游戏内常驻 HUD、收鱼反馈与救援／失败提示；商店商品格子及完整角色装备页保留现有交互。

原始图标由 `scripts/generate-hud-icons.py` 生成，共 21 个；索引见 `minimal-hud-icons.json`。资源位于 `Assets/HookIsland/Resources/UI/HudIcons.png`，关闭 mipmap，保留透明通道，不压缩。
