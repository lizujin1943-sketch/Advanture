# 回拉耐力反馈

## 玩家体验

- 普通鱼或食人鱼上钩并进入回拉阶段时，角色头顶显示当前耐力、耐力上限和消耗条；所有玩家各自显示。
- 剩余耐力超过 50% 为绿色，20%～50% 为黄色，20% 及以下为红色，并显示“耐力将尽”。
- 耐力耗尽后鱼挣脱，收回空钩，头顶短暂显示“鱼挣脱了 / 耐力耗尽 · 捕获失败”。本次捕获不会增加金币、鱼骨或捕获数。
- 鱼保留原模型完成挣扎、抛落、水花及下潜后才刷新；普通鱼和食人鱼均支持，联机与恢复状态同步。轨迹、版本和新增验证见 [鱼挣脱与落水表现](fish-escape-implementation.md)。
- 空钩、木材和钩拉队友不显示捕鱼耐力条。成功上岸和主动取消不显示挣脱提示。
- 商店、背包和菜单打开时隐藏头顶条；提示计时继续。退出房间、重开、载入较早状态时清理旧提示。

## 实现边界

`ReelingStaminaFeedback` 从确认状态中的 `FishId`、`HookedPiranha`、`Phase`、`Escapes` 判断表现状态，并维护每位玩家的短暂提示计时。首次收到已发生过挣脱的存档不重播旧提示，重复绘制同一确认帧不延长提示。

`ReelingStaminaOverlay` 读取 `FishingRules.MaxStamina` 与 `Fisher.Stamina`，使用已有角色插值位置投影绘制。`FishingEquipmentOverlay` 负责调用与房间生命周期清理。显示层不发出玩法命令，不扣除耐力，不结算奖励。

沿用 `HookGame` 的确定性回拉流程：先消耗同一耐力池，再检查耗尽和着岸；若耗尽与着岸发生在同一帧，按挣脱处理。现有房间同步和存档包含耐力及挣脱计数，UI 不新增网络消息。食人鱼捕获规则由敌人系统提供，表现读取同一组字段。
