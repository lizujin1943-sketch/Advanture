# 游戏资产制作与验收

按当前任务已确认的美术方向工作。若用户已确认设计，直接制作，不重新发起审批。对参考图做建模时，优先对齐大轮廓、身体比例、关节连接和材质分区，再补皮肤细节；增加随机噪声或细分面数不能替代结构。

## 默认还原流程（用户于 2026-11-17 明确要求）

1. 保存原图并分析结构。单张参考先补正、侧、后、俯等多视角设定；必要时补底视、翼根、口腔及肢体根部。用图像生成工具制作设定时保留原图身份和材质，并标注推断；生成图各视图可能不一致，要用尺寸和连接表解决，不能直接当工程蓝图。
2. 在建模前写明主要肢体的数量、连接位置、朝向、体厚和遮挡关系。章鱼类主触腕应围绕腕冠分布，脸部口须单独计数；吸盘朝向应随触腕腹面转动，不应全部朝着参考相机。
3. 先制作真正有体积的灰模，至少从正、侧、后、俯四个方向检查。正面接近而背面空缺、肢体共面或连接不成立时，应先修结构再做贴图。不要以轮廓 IoU 掩盖空间结构问题。
4. 结构通过后才补雕刻、材质、UV、贴图。斑纹位置、粗糙度和器官材质应逐部位对照参考；提高渲染分辨率或随机噪声不等于提高还原度。
5. 建模完成后制作骨骼、蒙皮和动作。要替换游戏资产时先读取现有的动作名、事件、尺度和根骨接口，保持玩法状态与显示分离。
6. 导出、回读、目标工程验证后交付多视角实模和动作证据。用户要求提交和 push 时，完成所需检查后再提交；保留未验证项说明。

这套流程是项目内今后所有按图还原任务的默认顺序，不只适用于克苏鲁 Boss。

同一组敌人的差异应落到轮廓、体态、移动方式和表面材质，不只换颜色。检查贴图在实际照明下是否仍能区分湿皮、角质、甲壳、膜和筋腱。游戏中主要观看距离下也应能辨认敌人类型。

为变形准备的网格需要关节处连续面流、合理厚度与拓扑密度。检查非流形、内部面、法线和松散顶点；不把所有边界都判成错误，眼睑、口腔等设计开口要结合用途判断。检查骨骼层级、蒙皮权重和极端姿态，特别是肩、髋、颚、触须根部。仅有骨骼或动作条目不表示绑定和动作已经可用。

Blender 程序材质通常不会原样进入 Unity。需要可移植材质时，制作 UV 并按目标渲染管线烘焙 Base Color、Normal、Roughness/Metallic 等通道，按项目 shader 的通道约定组装贴图。避免把光照阴影烘进普通 Base Color，除非风格明确要求。

导出前检查尺寸、轴向、根骨、动作命名、帧率与动作范围。只导出目标对象，避免带入参考板、灯光、测试物体。用独立临时场景重新导入 FBX/GLB，检查网格、材质、骨骼及动画是否存在；之后仍需在目标 Unity 工程检查动画播放和材质表现。仅通过 Blender 回读不能声称 Unity 接入完成。

交付清楚说明：实际完成了哪些源资产、哪些导出与动画已检查、哪些仍未在游戏中验证。渲染图、资产数量或脚本退出码不能代替视觉还原度验收。
