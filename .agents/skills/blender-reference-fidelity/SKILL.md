# Blender 按图建模与还原优化

先找出玩家一眼认出这个角色所依赖的形状，再决定在哪里花建模和贴图预算。用户只问差距时，给出有图可指的诊断；已要求修改时，在当前模型上验证诊断并修正。沿用已确认的设定和制作工具。

## 1. 把参考变成能复查的设计

- 指定主参考和目标机位。列出 3～5 个一旦丢失就会变成另一个角色的特征，写明位置和形状。例如“眉弓在鼻根合拢、遮住上眼缘”“一条粗腕从须下探出，向画面中下方内卷”。“精细”“写实”“有压迫感”都需要这样的对应物。
- 先补正、侧、背、俯视设定。在视图间标同一肢体的编号、根部、朝向和遮挡顺序；把原图可见、用户确认、遮挡处推测分别标记。多视图矛盾时回到主参考，保留可修改的推测。第三方重建截图可作视觉对照，模型拓扑、骨架和材质通道需另行查看源资产。
- 系列怪物先并排看同尺度剪影，给每只分配不同的重心、运动器官和行动姿态，再定材质分区和标志动作。先做一只代表怪的灰模和游戏距离试样，用已认可的美术方向指导批量制作。

## 2. 用灰模分别验证空间结构和画面姿态

1. 对齐原画相机的方位、俯仰、透视和主体占幅，再冻结相机和审图灯光。另设正交侧、背、俯视相机检查结构。保留每轮同机位图。
2. 看纯剪影和中性灰模，依次比外轮廓、主体长宽和厚度、肢体粗细变化、内部空隙与前后遮挡。用一个共同标尺看局部，例如用头宽比较眼距和腕根直径。正交图用于纠正结构，原画机位用于校回表情和姿势。
3. 分别画出肢体的**根部位置**与**末端投影**。根部可以向四周生长，前侧肢体仍可以回卷、交叉，在主视图压住中线。分别还原解剖对称和姿态不对称。头颅、翼和肢体的灰模仍像球、扇和等径软管时，先补骨点、承重面、渐缩和结构转折。
4. 镜头转到接头最暴露的一侧，去掉纹理与遮挡装饰，用掠射侧光检查轮廓和高光能否由主体转入分支。横向肥圈、环形折线、端面和统一粗度要回到截面与体积处理。按设定保留甲壳边、翼指和关节褶线。减面后在同一镜头复拍。

## 3. 分清低清、纹样走错和材质变平

- 同机位输出灰模、纯底色、最终材质。灰模已丢失的眉眼或吸盘凹口先修几何；纯底色中丢失的额纹、背腹分区或翼膜色块修贴图；转动灯光后消失的层次再检查法线、粗糙度和照明。
- 从大色区到标志斑纹，再到细纹与磨损。让纹理沿身体结构走，比较色斑形状、疏密、朝向和终止位置。转动肢体检查腹面花纹随扭转显隐。为皮肤、吸盘、甲壳、薄膜分别找对照部位。
- 遇到“糊”时，用相同裁切对照源纹理、Blender 最终分辨率渲染和引擎实际材质。依次核实预览缩放、主体占用像素、关键 UV 岛、烘焙、导入尺寸、压缩和 mip 层级。按首次出现模糊的环节修改；近景和玩家实际距离各复看一次。

## 4. 造型稳定后制作动作，在游戏资产上复查

- 在网格定型后开始正式绑定和动作。先用待机、主攻击和最大弯曲检验关节空间、支撑和拉伸。为动作安排蓄力、发力、跟随和回收，让根部带动梢端，口须和翼膜具有不同的延迟。用连续播放查看节奏，再逐帧看最容易穿插和开缝的位置。
- 有断肢的角色在设计时预留分离面。对连续皮肤检查减面后的边缘和蒙皮权重，在最终网格同时播放不同方向的肢体动作，复查接缝、残端和体积。动画进引擎后，按项目需要检查挂点、命中时刻、死亡收尾和旧 Boss 的动作接口。
- 交付说明分别写清**视觉上仍有的差距**、**实际验证的技术行为**和**未见部位的推测**。附同机位参考与实模、能暴露问题的第二视角，以及涉及改动的动作或游戏画面。按视觉影响修正最先失败的一层，再生成下游贴图、动作和导出件。

## 对照工具与实例

用 [compare_views.py](scripts/compare_views.py) 将参考和相近机位的渲染等宽并排，保留各自纵横比。工具需要 Python 3 与 Pillow。先按主体边界裁切，并保留卷尖和翼尖。可用 `--reference-mask` 和 `--model-mask` 各提供一张与对应输入等大的蒙版（物体白，背景黑），附加剪影行看中央留白和腕间空隙。相机俯仰、透视和姿态仍由制作者对齐。

```sh
# 从技能目录运行，坐标按各自原图像素填写，右边和下边为开区间
python3 scripts/compare_views.py reference.png render.png \
  --reference-box 0,0,1536,1024 --model-box 77,284,1400,1170 --out comparison.png
```

出现怪物过于抽象、腕根像插管、眼睛歪、动作全身同拍，或技术检查通过但造型仍不像时，查阅[沉钟镇怪物与带翼章鱼复盘](references/creature-postmortem.md)。
