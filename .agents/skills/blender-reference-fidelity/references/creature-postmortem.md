# 沉钟镇怪物与带翼章鱼复盘

## 第一轮失败在造型方向

首轮十种敌人已有模型和八十个动作片段，用户看完仍觉得“简约”“线条太生硬”“很抽象”。后来明确的美术目标是《异形》式完整非人生物结构，有相互支撑的甲壳、肌腱和软组织，气质阴暗。用户认可了“潮壳猎手”的概念图，这给了系列一个细节密度和生物可信度的标尺。其他种类仍各自需要清晰的外形、表面和运动方式。

重做时，把设定、灰模、材质球和可变形游戏模型分别标清。将十个剪影缩到敌人在战斗中通常占据的屏幕大小，遮掉颜色，逐一指出靠什么辨认；再由近景检查甲片下如何连着肌腱、关节在哪里屈伸。若只能靠颜色或名字区分，先改身体比例、承重方式和主要运动器官。动作先看一只的待机和主攻击，观察重量转移、发力点、末端延迟与回收；逐动作计数只用于检查交付完整性。

## 第二轮失败在单视图到立体结构的转换

| 反馈或现象 | 当时容易漏掉什么 | 下一次怎样在 Blender 里发现、修正 |
| --- | --- | --- |
| 正面看得到很多爪，绕到背面却空了 | 为了临摹正面，每根腕都朝向镜头，面部口须又混入了主腕计数 | 给八条主腕和口须分别编号，俯视标出根部到末端的路径，从背面逐根追溯。此 Boss 采用前四后四，其他生物依自身设定。 |
| 头下多了一圈肉，触腕根部都过粗 | 头壳、躯干和腕冠的交界堆出了没有原画依据的横圈，均匀粗的腕又把分支间的空隙堵住 | 侧背灰模观察头颅怎样收窄到腕冠，比较根部、中段、卷尖三处截面，保留腕间凹槽。此例腕根半径曾缩小 35%，到中段逐渐恢复；别把这个比例套在其他角色上。 |
| 正视时眼睛歪，校平后又可能丢掉凶相 | 斜视原画自带透视缩短，斜压的眉弓同时又是表情设计 | 在无倾斜的正交相机里，用身体中线校眼球中心、眼窝高度和颊鳍；再回原画机位看眉弓内端是否向下压住眼睛。按角色设定保留有意的不对称。 |
| 腕根像八根插进头部的管子 | 相交线可能被正面口须挡住；平滑着色也能留下明显的截面折角 | 隐藏口须，从侧后用宽侧光检查。让头部皮肤分叉到各腕根，根间形成浅蹼；沿根部看高光是否连续转弯，同时检查腕与腕之间还能否分辨。 |
| 高模看着顺，游戏网格弯腕时露缝 | 薄蹼体素重建容易起台阶；分别减面会改变原本配对的腕缘；静止接触的两圈顶点也可能受不同骨骼牵引 | 保留薄蹼形状，断离面移到腕身；减面后恢复边缘配对，让两侧使用一致的蒙皮权重。在成品上同时驱动两条腕向不同方向，检查裂缝、残端和形体塌陷。 |

本例留下了[形体修正对照](../../../../source-assets/creatures/winged-cthulhu/review/anatomy-revision.jpg)、[腕根侧背近景](../../../../source-assets/creatures/winged-cthulhu/review/crown-revision.jpg)和[运动接缝采样](../../../../source-assets/creatures/winged-cthulhu/review/crown-seams.json)。最后一项在 24 个动作中按帧抽样检验了 320 对腕缘点，回答的是“抽查姿态有没有开裂”。主视角的姿态仍需对原画单独复核。

## 第三轮差距在画面里的姿态、表情和表面

以下是对用户提供的 Tripo 正、背、俯视截图、[原画](../../../../source-assets/creatures/winged-cthulhu/ref/user-reference.png)及[本项目实模正面](../../../../source-assets/creatures/winged-cthulhu/review/game-material-front.png)的视觉比较。截图可用于研究可见体积、遮挡和明暗；拓扑、贴图通道和动画质量需要源模型才能判断。

| 部位 | 具体看哪里 | 修正后的复查 |
| --- | --- | --- |
| 前排主腕与中央留白 | 原画和对照模型都有粗腕从面须下探出并向中下部卷回，两侧弧线高低不同。项目实模把腕较均匀地向两侧展开，脸下留出较大空隙，视觉重量散开。 | 固定腕根，从中段调整曲率、进深和卷尖方向。主视图看中央卷腕、左右错落和腕间空隙，俯视与背面复核四周仍有主腕。 |
| 头壳、眉弓、面须 | 俯视能看出头壳的前后长轴与向额前收束的轮廓。眼缘深阴影、向内压的眉峰和面须前后层次，一起形成向下逼视的表情。正面头壳近圆、眼眶浅、口须同粗同长时，这个表情会变弱。 | 同时比对头部正侧和俯视比例；把面须分出显眼的中央长须和侧后短须，留出能看到下一层的缝。关闭发光和底色，看灰模眉眼是否仍成立。 |
| 头斑与背腹纹样 | 头顶大块深斑沿头壳分布，额中有较亮的小斑，腕背只有零星浅色痕。满布均匀圆点或细噪声，会抢走眉眼和额纹的对比。 | 先在纯底色中校主斑形状、位置和密度，再加次级变化与皮肤起伏。缩到游戏距离应仍能找到额中和腕背的标志。旋转灯光检查有没有把阴影画死在色图里。 |
| 吸盘与翼膜 | 吸盘有厚边、凹心和从粗腕到腕尖的尺度变化；腕扭转后，粉色腹面会露出、转侧、再被腕背遮住。翼指支撑着有张力的薄膜，主折线从翼指展开。 | 从背面和斜侧跟踪同一排吸盘，检查有没有变成始终朝前的粉色带。用斜光检查大吸盘凹口、翼指粗细和翼膜张弛，远景只保留对辨识有效的细节。 |
| “低清” | 低分辨预览、UV 分配不均、游戏导入降采样或大斑纹形状画错，缩图后都可能被称为“糊”。截图本身无法区分原因。 | 把同一块额纹和大吸盘各裁一块，逐级看源贴图、Blender 底色、渲染和游戏画面。按首次异常定位；若边缘清楚而斑形不对，回到纹样设计。 |

**可复用的一次审图判断。** 这只 Boss 优先试改靠前的一条主腕，让其经过面须下方后回卷。先交同机位灰模和俯视图，核对中央空隙、腕根方位、其他腕的遮挡；这些清楚后才值得重烘皮肤。这里记录的是下一轮可检验的修形方向。

## 进引擎之后

用玩家相机、游戏材质和关卡灯光重看正面、侧后和主攻击。黑暗气氛中仍应能辨出眼窝、前后腕与攻击预备姿态。独立断腕、喷墨出口和死亡动作各走一次正式入口；绑定或外形改变时复核弱点、挂点和命中采样。将“已导入”“动作能播放”“接缝已抽查”和“仍需修正的造型差异”各写一句。此例已有[游戏内画面](../../../../source-assets/creatures/winged-cthulhu/review/unity-town-front.png)和[历次修正记录](../../../../docs/winged-cthulhu-boss-replacement.md)，可直接追查每次验证的范围。
