日期：2026-11-11。当前阶段：**十种二维设定已齐，等待整套造型定稿；不是十种新模型完成。**

用户已确认潮壳猎手的设定方向，并要求十种全部制作、先设计再高度还原、仅用 Blender 制作模型。最新补充要求是外形与贴图都要有差异。模型与动画仍需按这些新设定重新制作；旧版资源和样模不能作为这批设定的还原结果。

## 阅读入口

- `index.html`：完整十种画廊，每张原图可放大，显示攻击特点及材质差异。
- `designs.json`：二维参考图来源、完整生成提示、内部类型映射。图片由内置图像工具生成，没有使用 Tripo、Meshy 或其他三维生成服务。
- `CreatureDesignWorkbench.blend`：设定板与独立材质试样，**不是怪物模型合集**。
- `material-specs.json`：十种独立材质规格。程序化材质试样不等于游戏贴图烘焙完成。

`DeepOne` 在正式玩法中的名称仍为「潮痕眷属」；「潮壳猎手」是获批的视觉重设计名称，不修改玩法枚举或规则。

## 还原检查

1. 先固定主视、侧视、正视相机与中性灯光，核对头身比、最高点、足部落点、器官位置与外轮廓。不同角度的二维参考可能存在生成误差，先在设计层解决，不靠模型硬凑互相矛盾的轮廓。
2. 再制作支撑组织与关节连接，确保不是分离的球体和圆柱；甲片要有真实边缘厚度，软体要有连续褶皱和受力方向。
3. 大中小三级表面细节分别处理。甲壳的生长纹、磨损与附着物；皮膜的血管、厚薄和皱褶；毒囊的斑驳、干痂和湿口都需要独立分布。
4. 每种单独烘焙颜色、法线、粗糙度、AO，按材质需要提供厚度/透射、发光或虹彩遮罩。不得用一张蓝黑皮肤贴图加颜色参数冒充十种纹理。
5. 绑定按各自身体结构制作。八类状态仍使用 Idle、Move、Windup、Attack、Recover、Hit、Emerge、Death 的表现接口，但不同物种不共享同一组摆动曲线。
6. 用实际 Blender 渲染与概念同角度并排检查；二维概念图不得充当模型截图。循环、脚滑、关节穿插和状态衔接另做动画检查。
7. 高模检查通过后再做游戏网格、贴图烘焙、LOD 和导出。高模面数多、动作数量齐、导入成功，都不代表视觉还原已通过。
