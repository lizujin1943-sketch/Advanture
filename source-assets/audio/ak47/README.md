# AK 游戏声音源

这个音库为庭院关卡原创。每一条声音都由本目录的固定种子和合成配方离线生成。制作使用的素材是带限噪声、压力脉冲、短促的非谐和共振和合成的空间脉冲响应。

| 资源 | 声部设计 | 游戏用途 |
| --- | --- | --- |
| `ShotClose01–05` | 居中的宽频攻击音和低频主体，随后出现偏侧的轻响、左右不同的早期反射和短扩散尾音 | 本机保留立体声，其他玩家的近场声按位置定位 |
| `ShotFar01–05` | 同组攻击音经过频带与包络重塑，叠加较慢的低中频涌动和更长的稀疏反射 | 单声道远场，随听者移动与近场声交叉淡化 |
| `ReloadShift` | 起伏的织物摩擦中带一次暗扣般的触碰 | 动作提示 0 |
| `ReloadContact` | 柔软的擦动之后，先后出现两下音色不同的短击 | 动作提示 1 |
| `ReloadSettle` | 轻而清楚的双触点收束到袖口摩擦 | 动作提示 2 |

## 重建和校核

在仓库根目录运行。已核对的环境为 Python 3.11.6 和 NumPy 1.26.1。

```sh
python3 source-assets/audio/ak47/render.py
python3 source-assets/audio/ak47/check_audio.py
```

生成器将 13 个 48 kHz、24 位 PCM 文件写入 Unity 的 `Resources/Weapons/AK47/Audio`。同一环境重跑可得到相同的文件内容。Unity 使用预加载的 PCM 音频，每个角色共用同一份资源，动作提示与发声尾音可以叠放。

试听文件位于 `artifacts/fortified-compound-game/ak47/AK47_AudioPreview.wav`，长 10.45 秒。前段可听到近场单发和连续五次发声，3.70 秒起是来自左右两个方位的远场声，5.87 秒起依次呈现三段动作音，结尾是一次近距离双响和远处应答。试听使用游戏内的音量与距离曲线。

校核程序读取实际的 WAV，检查声道、边界、音色差异、立体声兼容性、尾音、变体相关度，以及不同距离和时间偏移下两名玩家同时持续发声的峰值。当前 192 组叠加的最高四倍插值峰值是 −2.08 dBTP，本机单人连续发声为 −5.99 dBTP。
